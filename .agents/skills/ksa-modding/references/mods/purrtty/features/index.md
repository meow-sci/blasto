# Mod Feature

* [Anchoring a world-space quad to a part or to the camera](anchor-quad-to-part-or-camera.md) - Place a quad in KSA's camera-relative ego space from a vehicle part's position and rotation plus a user offset, follow the same Part object through decoupling and docking, or pin it in view space in front of the camera as a billboard
* [Bundled Nerd Fonts loaded into the ImGui atlas](nerd-font-loading-into-imgui-atlas.md) - Ship monospace Nerd Fonts with a renamed extension so KSA does not auto-load them, add them to the shared ImGui atlas at mod init, and size them per draw with PushFont
* [Click-through lock mode with a refocus hot zone](click-through-lock-mode-hot-zone.md) - Make an unfocused ImGui window ignore the mouse so clicks reach the game, and give it a tiny separate hot-zone window that refocuses it, with focus visuals drawn on the foreground draw list
* [Click-to-focus and input routing for world-space panels](ray-pick-focus-for-world-quads.md) - Pick the nearest world-space quad under the mouse with Cursor.GetEgoRay and Moller-Trumbore triangle tests, convert the hit to texture UV and terminal cells, and route keyboard and app-mouse input to that panel's shell while gating game input
* [Custom shell registry, lifecycle and PTY bridge](custom-shell-registry-and-lifecycle.md) - An ICustomShell interface with a validated, reflection-discovered registry and line-buffered base classes, adapted to the PTY process-manager interface so in-process shells (game console, SSH into a VM) behave exactly like real shells in the terminal
* [Failure-isolated Harmony patching with reload-safe statics](failure-isolated-harmony-patching.md) - Apply each Harmony patch class on its own with CreateClassProcessor inside a try/catch and classify patches as required or optional so a drifted game target never takes the mod down, plus a defensive lazy Harmony instance and static-state reset on unload
* [Filterable combo and form-table widgets for Brutal ImGui](imgui-filter-combo-and-form-widgets.md) - A combo box with a live substring filter that works around ImInputString only refreshing its length on a true InputText return, plus label-gutter form tables and a destructive button
* [Game menu with a ModMenu entry and a DrawProgramMenusHook fallback](game-menu-with-modmenu-fallback.md) - Draw the same mod menu through the ModMenu companion's attribute when it is installed, otherwise through a Harmony postfix on KSA's empty Program.DrawProgramMenusHook, keeping the draw path allocation-free and detection-free
* [Gate game input while a terminal is focused](gate-game-input-while-terminal-focused.md) - Harmony prefixes on Program.OnKey, GameSettings.OnKeyAll and the private Program.DispatchKeyEvent keep KSA hotkeys and mouse bindings from firing while the player types into a terminal, without stranding held keys
* [Handing PTY threads' output to the game frame](pty-threads-to-frame-tick-handoff.md) - The thread map that lets blocking PTY readers, writers and slow shell spawns feed a single-threaded engine that is only touched from the KSA main thread inside StarMapAfterGui, with bounded queues in both directions and synchronous close on the tick thread
* [Headless terminal surface with a renderer-neutral frame snapshot](headless-terminal-surface-and-frame-snapshot.md) - A backend that owns the native VT engine on one thread, accepts PTY bytes from any thread into a bounded inbox, and produces a dirty-aware TerminalFrame of pre-resolved cells that any frontend (ImGui window or world texture) can draw
* [Headless test suites for a KSA mod](headless-test-suites.md) - Four NUnit projects that test a game mod without the game, against the real KSA reference assemblies where cheap, with property tests, real-PTY OS-gated tests, and enforced rules that tests are silent on success and never use fixed sleeps
* [Hosting Windows shells in a ConPTY from inside the game](conpty-shell-hosting.md) - Spawn PowerShell, cmd or WSL attached to a Windows pseudoconsole from the KSA process, with null std handles, a never-sleeping pipe pump, a queued writer thread and a flush-then-close teardown that never closes a handle another thread is blocked on
* [ImGui keyboard and mouse to terminal input](imgui-keyboard-mouse-to-vt-input.md) - Turn ImGui key presses, the character queue, clipboard chords and mouse gestures into VT byte sequences via the engine encoders, with selection, app mouse reporting and AltGr handling
* [Injecting world-space draws after KSA's translucency pass](draw-after-translucency-pass-postfix.md) - A Harmony postfix on SuperMeshRenderSystem.RenderTranslucencyPass that issues tracked image barriers and opens its own dynamic-rendering scope over the scene's color and depth attachments, so custom translucent geometry draws after atmosphere, clouds and ocean have repainted the frame
* [Inter-mod shell contract shared through StarMap assembly imports](custom-shell-contract-via-assembly-imports.md) - Ship a small contract assembly that other mods resolve from purrTTY's AssemblyLoadContext by listing it in their mod.toml ImportedAssemblies, so both mods share one CustomShellRegistry.Instance, with a vendored fallback when purrTTY is absent
* [Kitty graphics images as ImGui Vulkan textures](kitty-graphics-as-imgui-vulkan-textures.md) - Upload images decoded from the kitty graphics protocol into SimpleVkTexture objects, register them with KSA's ImGui Vulkan backend as ImTextureRef, and draw them in grid-aligned z-bands with an LRU cache under the shared descriptor pool
* [KSA upgrade coupling review skill](ksa-upgrade-coupling-review-skill.md) - An AI-assistant skill that drives a diff of two decompiled KSA builds against a catalog of every place the mod couples to game code, classified by how each coupling fails (compile, patch load, reflection, silent behavior)
* [Logging through a Brutal LogCategory in a shared assembly](brutal-logging-category.md) - Give the mod one Brutal.Logging LogCategory in a tiny assembly so every project, and other mods that import it, log into KSA's console, stdout and monitor with interpolated-string handlers and caller info
* [Multi-window terminals with tabs, hidden chrome and grid snap](terminal-window-chrome-tabs-and-resize-snap.md) - Run several title-bar-less ImGui terminal windows with tab bars, chrome that fades without changing layout, an invisible grid button that stops drag-moves, and a resize that snaps to whole cells
* [Named terminal registry and per-target theme dialog](named-terminal-registry-and-theme-dialog.md) - Address every terminal, 2D ImGui window or in-world texture, by a unique case-insensitive name through one INamedTerminal registry, and drive a non-modal dialog that applies whole appearance bundles to the selected target
* [One-zip cross-platform build, deploy and release pipeline](cross-platform-build-and-release.md) - Resolve KSA reference assemblies from an env var or a sibling checkout with a fail-fast check, wipe-and-copy an allow-listed payload plus all native libraries into the mod folder on every build, and test on three OSes before stamping and publishing a release zip
* [OSC 52 clipboard writes into the game clipboard](osc52-clipboard-sidecar.md) - Tee the PTY byte stream through a small managed OSC scanner so remote and local programs can set the system clipboard via OSC 52, applied with ImGui.SetClipboardText on the main thread
* [Per-platform native library resolver for a mod's AssemblyLoadContext](per-platform-native-library-resolver.md) - A ModuleInitializer installs NativeLibrary.SetDllImportResolver so P/Invoke finds the right per-OS shared library beside the mod DLL inside StarMap's mod AssemblyLoadContext, plus a libc resolver for glibc and macOS
* [POSIX pty shells spawned without fork](posix-pty-spawn-without-fork.md) - Allocate a pty with posix_openpt and launch the shell with posix_spawnp (SETSID, slave opened as stdin, signal state reset) so a multi-gigabyte, heavily threaded game process never forks, with the arm64 variadic ioctl fix and a poll-based reader
* [Rebindable toggle hotkey with a capture modal](rebindable-toggle-hotkey.md) - A configurable key-plus-modifiers hotkey read from ImGui IO each frame, with a press-to-capture modal, text-field suppression and first-frame swallowing when it opens the terminal
* [Render-to-texture with a second ImGui context and Vulkan backend](offscreen-imgui-context-render-to-texture.md) - Draw ImGui UI into a mod-owned off-screen Vulkan image by creating a secondary ImGui context that shares the game's font atlas, a second instance of KSA's ImGuiBackendVulkanImpl bound to a mod render pass, and a mod-owned command pool, ring of fences and queue submit
* [Safe Vulkan teardown and live resize for mod-owned GPU resources](vulkan-resource-teardown-discipline.md) - Stop recording a resource immediately, free it only after the frames that may reference it have completed plus a device WaitIdle, rebuild render targets in place for live resizes, and never touch the Vulkan device in StarMapUnload because the game has already destroyed it
* [Saved terminal layouts with startup commands](saved-terminal-layouts.md) - Save and restore named sets of 2D and in-world terminals as hand-emitted TOML, applied only on user request with name-collision skips, per-terminal startup commands typed into the shell, and an MRU command history
* [Shell detection and launch command resolution](shell-detection-and-command-resolution.md) - Detect installed shells, WSL distributions and /etc/shells entries once on a background thread with bounded waits, define availability as resolvability, and build Windows command lines with CommandLineToArgvW quoting versus discrete argv on Unix
* [Terminal grid drawn with ImGui draw lists](terminal-grid-drawlist-renderer.md) - Paint a full terminal cell grid (backgrounds, glyph runs, block and braille glyphs, decorations, cursor) into an ImGui window draw list every frame with run batching
* [The KSA game console as a terminal shell](game-console-shell.md) - A custom shell that runs typed lines through KSA's TerminalInterface and captures the console's colored output with a Harmony postfix on ConsoleWindow.Print, gated so only output produced during the command is captured
* [TOML settings and alacritty-format themes](toml-themes-and-settings.md) - Persist mod settings with Tomlyn under the KSA Documents folder, load bundled and user color schemes in alacritty TOML format, and write every file atomically with temp-then-rename
* [Vendored libghostty-vt binding as the terminal engine](vendored-libghostty-vt-binding.md) - Delegate all VT emulation to Ghostty's standalone libghostty-vt through a vendored, pruned and patched .NET binding with source-generated P/Invoke, a managed packed-cell decoder and a startup layout self-check
* [World-space textured quad pipeline with a runtime-compiled shader](world-space-quad-pipeline-custom-shader.md) - Build a dynamic-rendering Vulkan pipeline that draws a textured quad into KSA's scene target, reusing the game's UnlitMeshVert vertex shader, compiling a premultiplied-alpha fragment shader at runtime with the bundled shaderc, depth-testing against reverse-Z without writing depth
