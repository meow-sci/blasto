# Subdirectories

* [control](control/index.md) - Getting commands in: game-thread command queues, timed scripts, AI agents over MCP and typed external clients.
* [network](network/index.md) - Talking to networks and devices from inside the game: HTTP and MQTT servers, serial and bus protocols, and outgoing HTTP requests.
* [processes](processes/index.md) - Running and binding code that is not managed C#: child processes and virtual machines, host-guest transports and native C libraries.
* [telemetry](telemetry/index.md) - Getting game state out safely: immutable snapshots for other threads, derived flight events and recording to files.
* [terminals](terminals/index.md) - Terminals inside the game: pty sessions handed to the frame, clipboard escape codes and streaming the game screen into a terminal.
