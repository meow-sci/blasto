# Mod Feature

* [API surface pinning and KSA upgrade diffing](api-surface-pinning-and-diff.md) - Record every KSA type and member the compiled mod binds to from its own metadata tables, pin Harmony targets into that record with never-called PinTheSignature methods, lock the game assemblies by SHA-256, and narrow a KSA update's decompiled diff to what the mod actually touches
* [Art and audio pipeline tooling](art-and-audio-pipeline-tooling.md) - Offline checks and generators for a mod's authored assets, covering GLB bounds from accessor min/max, coplanar-face and zero-UV detection, atlas dilation, Blender previews, XML Id and path validation against Core, and engine loops cut from CC0 recordings with their provenance
* [Build, deploy, package and release pipeline](package-deploy-release.md) - Resolve the game's DLLs from a tiered search without committing them, deploy a developer build with a marker file after validating assets, package a symbol-free archive that refuses foreign DLLs, and release with semantic-release, a draft GitHub release and SpaceDock publishing
* [Car panel and ModMenu entry](car-panel-and-modmenu.md) - A closable ImGui panel drawn from the GUI hook only while a car is flown, built with flags that never take the keyboard so the flight keys keep driving, plus an optional ModMenu entry declared through a name-matched attribute copy
* [Car part assets: GLB atlases, PBR materials and subparts](car-part-assets-glb-pbr.md) - Declare a new part's look in an Assets XML bundle with a MeshAtlas GLB, a PbrMaterial with diffuse, normal, ORM and emissive PNGs, one SubPart template per moving body, a glass subpart, and a Part that instances and places them
* [Car part game data](car-part-gamedata.md) - Make a mod part a drivable root craft in GameData XML with its own EditorTagDef category, a node connector, a Control command source, battery and light switch, a box-shaped mass for yaw inertia and colliders that stay clear of the ground at rest
* [Coloured emissive lenses per subpart](coloured-emissive-lenses.md) - Make a tail lens glow red and a marker amber by setting KSA's add-emissive-colour state bit and colour per drawn subpart from a Harmony postfix on the private PartTreeRenderData.WriteState, with the lenses cut out of the body mesh as their own subparts
* [Craft mover with mouse picking and ground placement](craft-mover-mouse-pick-place.md) - Pick a craft with one click by projecting every vehicle to the screen, find the ground under the cursor by walking a camera ray against the height field, draw gizmo rings anchored to the craft's rendered position, and set the craft down once with Vehicle.TeleportToLocation
* [Drive with the flight keys](drive-with-flight-keys.md) - Map a car's throttle, brake, steering and air controls onto KSA's existing vehicle key bindings by reading the craft's held thruster flags, reflected engine switch and throttle keys, and a patched-in sprint key
* [Driver kitten's hands on the steering wheel](driver-hands-steering-ik.md) - Attach a custom IAnimProcessor to the seated driver kitten's character model through a reflected private field and solve each arm onto the turning steering-wheel rim with a two-bone IK after the seated animation and before skinning
* [Engine sound from two crossfaded, re-pitched loops](engine-sound-crossfade.md) - Ship mod-owned engine samples as Sound XML assets and play an idle loop and a loaded loop together on KSA's FMOD channels, crossfaded by throttle and re-pitched every frame to the simulated RPM
* [File-drop command bridge](file-drop-command-bridge.md) - Drive a running game from outside by dropping JSON command files into a folder beside the mod's log and reading JSON replies back, polled once a frame from the frame postfix, with multi-frame commands for stepping the world, spawning craft, driving cars and taking screenshots
* [Headlamps and tail lamps as KSA spotlights](headlights-as-spotlights.md) - Submit a car's head and tail lamps as KSA spot lights from a Harmony postfix on PartTree.UpdateRenderData, the only point where per-frame lights survive LightSystem.ClearLights, and keep them in step with the part's own light switch
* [Headless simulation tests and the Sim/Ksa boundary](headless-sim-tests.md) - Split the mod into a KSA-free Sim folder and a KSA-facing Ksa folder, link Sim wholesale into an xUnit project that references no game assembly, and drive the car model on a rigid-body rig so physics changes are tested without the game, with CI and hooks running the same checks
* [Inject wheel forces from a Vehicle.PrepareWorker prefix](prepareworker-impulse-injection.md) - Write a car's per-step linear and angular impulse straight into the vehicle's kinematic state from a Harmony prefix on Vehicle.PrepareWorker, the only main-thread window where the write reaches the physics worker
* [Keep a craft with mod thrust off rails](keep-thrusting-craft-off-rails.md) - Stop KSA from putting a car onto its orbit while the mod's rockets burn by answering yes to the private PhysicsBubble.KittenWantsWake, the per-craft question both rails decisions ask, and rebuild a coasting car from its orbit before pushing it
* [KSA MCP server over the bridge](ksa-mcp-server.md) - A stdlib-only Python MCP server, registered in .mcp.json, that turns the mod's file-drop bridge into agent tools for launching, loading, stepping, driving and photographing a running game, returning screenshots inline with contact sheets and temporal-noise maps
* [KSA's engine panel and throttle gauge for a craft with no engine](engine-hud-for-engineless-craft.md) - Show KSA's own engine-control gauge panel for an engineless car that flies, withhold the "No active engines" alert, and put the mod's throttle on the stock throttle gauge by writing Vehicle._manualControlInputs between the GUI pass and UpdateGauges
* [Launch pad surface contact](launch-pad-surface-contact.md) - Rebuild a body's launch-pad colliders from their StaticObjectTemplate data, posed the way ConstraintSim poses them, and drop a ray from each wheel hub onto those boxes and cylinders so a car drives on the pad deck
* [Once-per-frame car step from two StarMap hooks, with a registry of the mod's craft](frame-step-latch-and-car-registry.md) - Run per-frame work once from whichever of StarMapAfterGui or StarMapAfterOnFrame fires first, release the latch in a finally on the hook KSA always calls, and keep a per-frame registry of the craft carrying the mod's part
* [One folder as both a content mod and a StarMap code mod](mod-folder-content-and-code-mod.md) - A single mod folder whose mod.toml is read by KSA for its explicitly listed asset XML files and by StarMap for the entry assembly, with the XML at the root beside Meshes, Textures and Sounds and a csproj that copies them next to the DLL
* [Per-mod log file, build stamp and fault limiter](mod-log-file.md) - Keep the mod's own batched, thread-safe log file beside KSA's logs with the previous session preserved, stamp the KSA build the DLL was compiled for into the assembly, detect developer installs by a marker file, and disable the mod after repeated faults
* [Pose subparts at runtime](pose-subparts-at-runtime.md) - Animate wheels, suspension arms, squashed coil-overs, the steering wheel, iris blades and scoops by rewriting each subpart's parent-relative transform every frame from the GUI hook, with a frame-postfix fallback when the UI is hidden
* [Rocket lift, hover, boost and downforce as velocity deltas](rocket-lift-hover-boost-downforce.md) - Fly a car on thrust the mod applies itself by adding lift, hover, boost and downforce pushes to the vehicle's velocity and spin in the same Vehicle.PrepareWorker window as the springs, written as shares of the step so time warp cannot make them overshoot
* [Rocket roar from KSA's stock engine sound, with no engine](rocket-sound-without-engine.md) - Play Core's DefaultEngineSoundBehavior on a channel the mod owns and feed it the Throttle, Distance, Pressure and Iva parameters each frame, exactly as Vehicle.UpdateAudio does for a real nozzle
* [Seated crew of unflown cars](seated-crew-of-unflown-craft.md) - Postfix Vehicle.UpdateSeatedCrewRenderData so the kittens sitting in every car that is not the controlled vehicle are drawn too, with the same viewport, camera matrix and player step KSA used for the flown craft
* [Seats and EVA doors](seats-and-eva-doors.md) - Give a mod part crew seats with IVASeat entries placed at the kitten's eye, and let kittens get out and climb back in through EVADoor modules on mesh-less hidden subparts beside each seat
* [Spawn a saved craft parked at a latitude and longitude](spawn-parked-craft.md) - Build a library craft on a placeholder orbit inside ConstraintSim.UnlockShapesBlocking, add it to its parent's Children so per-frame data runs, and set it down with Vehicle.TeleportToLocation
* [Switchable scoop colliders and rocks that come loose](scoop-colliders-and-loose-clutter.md) - Deploy a scoop blade by moving stowed collider boxes out of the hull at runtime through ColliderModule.PositionPartAsmb and NeedsColliderUpdate, and make ground clutter pushable by lowering BubbleClutterStatics.DisplaceEnergyPerKg, enabling clutter collisions and lightening rock templates
* [Terrain contact under each wheel](terrain-contact-under-wheels.md) - Find the ground under each wheel hub by sampling the body's height field along the hub's planet-fixed direction, using the vehicle's physics state rather than its analytic orbit position
* [Vehicle library presets](vehicle-library-presets.md) - Install each car as a ready-to-launch whole craft by writing a vehicle.xml with a single RootPartRef and a meta.toml into the player's Vehicles library, mirroring Core's default vehicles
* [Veto structural destruction for one kind of craft](crash-veto.md) - Spare a car from KSA's crash destruction with a Harmony prefix on Universe.DestroyVehicleFromEvent that returns false for it, and close the separate part-failure path by setting CrashTolerance far past any contact pressure on the car's Part
* [Volumetric exhaust plumes with no engine behind them](exhaust-plumes-without-engine.md) - Draw KSA's own volumetric rocket plumes at arbitrary nozzles by building VolumetricExhaustInstance objects from a Core template and submitting them from a Harmony postfix on Vehicle.AddVolumetricExhaustInstances, with gas numbers the mod chooses
* [Wheel, suspension and tyre model](wheel-suspension-tyre-model.md) - A per-wheel spring-damper with anti-roll bars, a friction-circle tyre, a speed-limited steering lock, a linear drive-force falloff and a cosmetic gearbox, stepped once a frame as one impulse for the whole car
