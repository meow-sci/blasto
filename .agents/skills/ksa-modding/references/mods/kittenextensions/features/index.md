# Mod Feature

* [Combined GameData XML document](gamedata-document.md) - Before the game reads any mod XML, KittenExtensions parses every manifest mod's mod.toml, imports its planet mesh, system, asset and patch files into one in-memory Root/Mod document with a RelPath on each file root, and runs every Patch in manifest order
* [Continued fork with a new mod id and the old assembly name](continued-fork-identity.md) - KittenExtensions Continued installs under the new mod id KittenExtensionsContinued but keeps the KittenExtensions assembly name and namespace, so dependents keep binding through a non-optional StarMap dependency that imports that assembly
* [Custom XML asset types via KxAsset attributes](custom-xml-asset-types.md) - Any loaded assembly that declares its own KittenExtensions.KxAsset or KxAssetInject attribute gets its tagged classes added as new XML element names through XmlAttributeOverrides and a rebuild of every cached game serializer
* [ImGui tree view widget](imgui-tree-view.md) - ImGuiTreeView<N, A> draws large trees with custom arrows, guide lines and selection fills on a split draw list, keeps open state in ImGui storage and uses static abstract adapters for node equality and parents
* [MSBuild-generated mod.toml and deploy](msbuild-mod-toml-generation.md) - CopyOutput.targets regenerates mod.toml on every build from MSBuild properties and items, then replaces Release/<ModName> and the installed mod folder, while KSADLLs.props globs the game DLLs as non-private references
* [Patch debug stepper](patch-debug-stepper.md) - With debug = true on the KittenExtensionsContinued manifest entry, startup dumps the unpatched GameData document to root.xml and opens an ImGui debugger that steps patch actions, tests XPath and browses the live document
* [Patch session log](patch-session-log.md) - An always-on KittenExtensions.log, reset at StarMapBeforeMain, that hooks the patch executor's events to log every applied or failed document mutation with old and new values and a per-file summary
* [Pre-game ImGui popup loop and fatal patch errors](pre-game-popup-loop.md) - KittenExtensions shows its debugger and fatal error dialog before the game loop exists by subclassing KSA.Popup and pumping its own GLFW, ImGui and Vulkan frame in a loop copied from SelectSystem, then exits after a patch error
* [XML patch files and XPathPatch operations](xpath-patch-operations.md) - A mod lists patch files under a patches key in its mod.toml, and each Patch file holds XPathPatch operations (Copy, Merge, Delete, If, IfAny, IfNone, With, SetVar) whose XPath 1.0 Path and From expressions select nodes in the combined GameData document
* [XmlLoader call-site redirect](xmlloader-call-site-redirect.md) - A Harmony transpiler swaps every XmlLoader.Load<T> call in four Mod loader methods for XmlPatcher.Load<T>, which deserializes the patched in-memory node with an override-aware serializer instead of reading the file
