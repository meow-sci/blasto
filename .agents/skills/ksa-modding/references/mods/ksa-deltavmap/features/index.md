# Mod Feature

* [Closed-form patched-conic transfer model](patched-conic-transfer-model.md) - Hohmann transfers between sibling bodies with Oberth-combined ejection and capture, cached per unordered body pair for the life of a loaded system, plus comet, multiple-star, atmospheric ascent, landing, plane-change and transfer-time terms
* [Debug-build validation dumps, perf scopes and once-only logging](in-game-validation-dumps-and-perf.md) - In DEBUG builds the AfterGui hook runs a one-shot delta-v, visual-tree and layout dump (log lines plus SVG/text files) on the first loaded system, ref-struct PerfTracker scopes time the hot paths, and keyed WarnOnce/ErrorOnce logging keeps per-frame failures from flooding the log
* [Ego-centric re-rooting that follows the controlled vessel](ego-rerooting-and-vessel-follow.md) - Turns the physical celestial tree inside out at the body the vessel is in, climbing a spine of ancestor hub buses, and re-roots on window open, vessel switch, star-system crossing, System menu pick or Shift+click
* [Game-free subway-map layout engine with three modes](three-layout-modes.md) - A game-type-free pipeline lays out the delta-v tree as cumulative-down bands, gravity wells on a low-orbit spine, or a Barnes-Hut spring web, measuring labels with ImGui.CalcTextSize
* [Headless harness tests that run against the real game simulation](headless-harness-tests.md) - A test-only StarMap mod depending on HeadlessHarness and DeltaVMap runs IHarnessTest classes on the live game and compares the mod's results with stock code, including private planner methods via reflection
* [Interstellar routes and fuel](interstellar-routes-and-fuel.md) - Prices a trip to another star system as one leg at a chosen cruise speed, using patched-conic gravity-well chains, a Newtonian coast, cheapest and fastest-affordable speed searches, and the game's own antimatter-drive integrator for fuel
* [Live celestial forest of every star system, cached per loaded system](live-celestial-system-graph.md) - Builds one physical tree per independent root (fixed star or barycenter) straight from the loaded CelestialSystem, reads every body's mass, radius, SOI, orbit and atmosphere once, and rebuilds only when Universe.CurrentSystem changes instance
* [Menu-bar entry and stock ImGuiWindow subclass drawn from AfterGui](map-window-and-menu-entry.md) - A Harmony postfix on the empty Program.DrawProgramMenusHook adds a top-level menu, and a KSA.ImGuiWindow subclass created lazily from that menu is drawn every frame from StarMapAfterGui
* [Offline test executable that links the mod's game-free kernels without KSA.dll](offline-layout-and-math-tests.md) - A console test exe source-links the mod's game-free layout engine and math kernels without KSA.dll, asserts overlaps and formulas against synthetic trees and stock values, and writes SVG dumps
* [Open the stock Transfer Planner preselected on an interstellar plan](stock-transfer-planner-bridge.md) - Binds the private static fields and SetTransferInfo of KSA.TransferPlanner once with AccessTools FieldRef and delegates, then replays the exact writes the stock PLAN TYPE, SOURCE and DESTINATION combos make, degrading to just opening the window when a key is missing
* [Other star systems as separate graph parts joined by dashed interstellar connectors](multi-system-scene-composition.md) - Cuts the visual tree at its Interstellar edges, lays out each other star system as its own collapsed or expanded part (cached per root build), places the parts in a strip beside the never-moved home map with routed dashed connectors, and keeps the clicked node on screen when a system opens or closes
* [Panel rows built on the game's ConsoleWidgets kit](stock-console-widget-panels.md) - The side panels draw toggles, presets, log sliders, readouts and status lines with the game's ConsoleWidgets and ConsoleStyle kit, copying the stock Transfer Planner's slider row
* [Pannable, zoomable ImGui canvas that draws the subway map with draw-list primitives](subway-map-canvas-rendering.md) - Draws the laid-out map every frame on the window draw list inside a clipped child region, with a full-canvas InvisibleButton that owns drag and wheel, screen-fixed KSP-style node glyphs shared with the legend, per-system colors, priority-ordered label culling and allocation-free cached text
* [Per-body state ladder and "you are here"](body-state-ladder-and-you-are-here.md) - Each body becomes a vertical ladder of places (surface, low orbit, stationary, SOI edge, intercept; a 1 AU parking orbit for stars and barycenters) derived from live celestial data, and the controlled vessel's orbit is classified onto it as the route origin
* [Route finding and accumulation](route-finding-and-accumulation.md) - Click a node to route from "you are here" along the unique tree path (lowest common ancestor), sum the per-leg burns with from-surface, landing, aerobraking, plane-change and return-trip toggles, and show a per-segment breakdown with a display-time piloting margin
* [Search, focus, isolate and minor-body aggregation for dense systems](search-focus-isolate-and-aggregation.md) - Collapses a hub's minor bodies into one "+N" node above a threshold, folds distant star systems past eight, and lets a body-name search reveal, center and isolate any single body out of thousands, behind an 8,000-node never-hang ceiling
* [Shared MSBuild deploy targets, release zip and SpaceDock publishing](mod-deploy-targets-and-release.md) - A shared ModDeploy.targets deploys into the mods folder with a locked-DLL guard, launch-profile generation and a deploy stamp, and a GitHub workflow publishes release zips to SpaceDock
* [Transfer windows list and live polar phase clock](transfer-windows-and-phase-clock.md) - For the map root and every shown sibling it computes the Hohmann lead angle, live phase, countdown, synodic period and ejection angle with the same branches as the game's OrbitalTransfers.AlignmentTime, and draws a resizable list plus a polar phase clock whose hover lights the matching map node
* [Transfer-window markers drawn into the game's 3D map mode](map-mode-transfer-overlay.md) - While the camera is in map mode it projects each sibling's future position at its next window, the live planet-star-planet phase angle and an ejection-angle gizmo from orbit (CCE) coordinates to screen with the viewport camera's EclToScreen and draws them on the ImGui background draw list
* [Vehicle staged delta-v readout](vehicle-staged-dv-readout.md) - Reads the vessel's total staged delta-v from a private instance of the game's SequencePerformanceList, gated by a cheap change signature and a reflected PartTree._derivedDirty check so the UI draw never races the vehicle solver
