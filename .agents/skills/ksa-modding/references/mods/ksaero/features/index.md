# Mod Feature

* [Aero readout window](aero-readout-window.md) - An auto-sized ImGui window drawn from StarMapAfterGui that finds the controlled vehicle, reads its main-thread atmosphere and kinematic state and re-runs the physics model to show Mach, q, angle of attack, lift and drag
* [Body-of-revolution aerodynamics](body-of-revolution-aerodynamics.md) - Replaces stock bounding-box drag with an axisymmetric cylinder model that gives angle-of-attack drag, lift with a stall, tail-first lift and a transonic drag rise, evaluated per substep inside the vehicle solver
* [Build and deploy targets](mod-deploy-targets.md) - An MSBuild setup that compiles against the installed game's DLLs via a KsaDir property, takes Harmony and StarMap.API from NuGet, deploys the DLL and mod.toml into the KSA mods folder on every build with a locked-file diagnosis and a deploy stamp, and zips a release
* [ComputeDrag call-site transpiler](computedrag-call-site-transpiler.md) - A Harmony transpiler on PhysicsStates.ComputeDerivatives that retargets only the atmospheric ComputeDrag call to a same-signature replacement, found by scanning the call's argument IL for the AtmosphericDensity load
* [Game version check](game-version-check.md) - At StarMapAllModsLoaded the mod compares VersionInfo.Current.VersionString with the build it was tested on and logs a warning on mismatch, leaving the real go or no-go decision to the transpiler's shape check
* [Headless model tests](headless-model-tests.md) - A console project that source-links the game-free AeroModel.cs, checks physical invariants of the aero model over thousands of attitudes and Mach numbers, and prints coefficient tables, all without KSA installed
* [Mach number from the game atmosphere](mach-from-game-atmosphere.md) - Derives the speed of sound as sqrt(1.4 p / rho) from the pressure and density KSA already stores per vehicle, which is a per-body constant because KSA atmospheres are isothermal exponentials
* [Patch refusal and rollback](patch-refusal-and-rollback.md) - KSAero throws from its own transpiler when the target method has changed shape, then catches the failure, removes only its own Harmony patches by id and leaves the stock behaviour and its UI switched off
* [Stock ComputeDrag delegate fallback](stock-drag-delegate-fallback.md) - A typed delegate with matching in and ref parameters, created once with AccessTools.MethodDelegate, lets the replacement force function call the private stock PhysicsStates.ComputeDrag whenever it cannot model the vehicle
