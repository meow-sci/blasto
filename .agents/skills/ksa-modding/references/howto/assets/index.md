# Subdirectories

* [asset-xml](asset-xml/index.md) - The asset XML vocabulary and its plumbing: element reference, load order, ids and paths, custom element types and data files shared between mods.
* [models-and-textures](models-and-textures/index.md) - Models and textures: glTF and PBR declarations, part models, Blender export, runtime GLB import and compositing over stock textures.
* [validation](validation/index.md) - Catching silent asset failures before and while the game runs: mesh checks, XML reference validation and XML patch debugging.
* [xml-patching](xml-patching/index.md) - Changing the game's own XML without copying it: KittenExtensions patches, XPath recipes and loader redirects to patched copies.
