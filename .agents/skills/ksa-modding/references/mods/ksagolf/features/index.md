# Mod Feature

* [API surface record and assembly lock](api-surface-and-assembly-lock.md) - Pinning the KSA build a mod compiles against with a hash lock, recording the exact game members the compiled DLL binds to from its metadata tables, and narrowing each KSA update to the changes that can affect the mod
* [Borrowing the main view and handing it back](borrowed-chase-camera.md) - KSA-free rules for borrowing the player's main view: who may hold it, a hand-back in two halves (mode and follow) with the field of view always returned, a chase pose, KSA-style orbit drag, a carried roll and an evened-out step
* [Content-plus-code mod layout](content-and-code-mod-layout.md) - One mod folder that KSA loads as a content mod (asset XML, meshes, textures, sounds) and StarMap loads as a code mod, built so the game assemblies are referenced but never shipped
* [Course colliders registered as ground clutter](course-colliders-as-clutter.md) - Static Bepu boxes added to every nearby physics bubble from worker-thread prefixes on ConstraintSim and registered by reflection as infinite-mass ground clutter, the only kind of mod-made static the engine lets a kitten stand on
* [Course grid model and JSON save file](course-grid-and-save-file.md) - An engine-free minigolf course model with ports as cell edges, an append-only piece catalogue with non-rectangular footprints and mirror twins, a playability check, port snapping, undo and redo, and a versioned JSON file anchored by latitude, longitude, heading and height above ground
* [Course surface from exact shapes](course-surface-exact-shapes.md) - The minigolf course as the ball meets it, built from exact rail boxes, posts, felt heights and cup profiles shared with the Blender models, with rails swept rather than sampled and the planet's ground beyond the pieces
* [Craft mover](craft-mover.md) - Click a craft to pick it up and click the ground to set it down, or send the flown craft to any body, through Vehicle.TeleportToLocation so the engine rebuilds an upright resting state from the craft's bounding box
* [Cursor picking and the terrain ray](cursor-picking-and-terrain-ray.md) - Turning the ImGui cursor into a world ray through the right viewport's camera, walking that ray to the first place it goes under the terrain, and picking the craft nearest the cursor on screen with a per-item reach
* [Degrading Harmony patches with per-feature ids and signature pins](degrading-harmony-patches.md) - One static class per Harmony patch, each under its own Harmony id, looking its target up defensively, logging once and standing down instead of throwing, pinned into the API record by a never-called call, and removed by a fault limit rather than by StarMapUnload
* [Developer panel and menu-bar entry](developer-panel-and-menu-bar.md) - An ImGui panel reached from an entry in ImGui's own main menu bar opened before KSA's GUI pass (a separate bar from KSA's), an optional ModMenu entry through a copied attribute, a floating reopen button, wrapped tooltips and slow-motion controls
* [Drawing a mod's static mesh into every viewport](mod-mesh-draw-hook.md) - Postfix SuperMeshRenderSystem.ClearBuckets so a mod's own StaticMeshRenderable (the ball, course pieces, a see-through ghost) is submitted after the engine clears each viewport's mesh buckets, the one moment such a draw survives to the render
* [Dual-hook frame stepping on simulated time](dual-hook-frame-stepping.md) - Running a mod's per-frame simulation exactly once per frame from whichever of three hooks reaches it first (the GUI postfix, a Harmony prefix on Program.OnFrameCelestials, or the frame postfix), latched and always released, and integrated on the engine's applied sim step rather than player time
* [File command bridge and MCP server](file-command-bridge.md) - Driving a running game from outside through JSON command files dropped beside the log and answered in an outbox, gated to developer installs, with a stdlib MCP server that turns the commands into agent tools
* [First-person kitten view that keeps the shadow](first-person-kitten-view.md) - Look out through a kitten's eyes by stripping its skeleton for the main view only, re-skinning the whole kitten into the shadow pool, holding its walking facing on the mouse look, and posing the eye from the head bone each frame
* [Frame and epoch draw anchor](frame-epoch-draw-anchor.md) - Drawing world-space gizmos next to a craft without the 500 m-per-frame ecliptic error, by anchoring every overlay to the craft's rendered Ego position sampled this frame and adding Ecl offsets measured against the platform sample from the simulation step
* [GLB authoring pipeline and mesh checks](glb-authoring-and-mesh-checks.md) - Authoring KSA meshes live in Blender over MCP with a human geometry sign-off, an export contract checked against Core's atlases, and offline Python checkers that catch zero-UV-area faces, coplanar z-fighting, unmaterialed primitives and bad asset references before the game ever loads them
* [Golf ball physics in the body-fixed frame](golf-ball-physics.md) - A mod-simulated golf ball integrated in the rotating body-fixed frame of the world under it, with flight, bounce, rolling resistance, slope rest and quadratic drag scaled by the engine's own air and sea density
* [Headless simulation tests behind a Sim/Ksa boundary](headless-sim-tests.md) - Splitting the mod into a KSA-free Sim folder linked wholesale into an xUnit project and a Ksa folder that binds to the game, so the maths runs headlessly and the boundary enforces itself at build time
* [Launch-site surface by raycast into a copied collider](launch-site-surface-raycast.md) - A Harmony prefix on Universe.ExecuteNextVehicleSolvers copies each launch site's Bepu compound collider and terrain-tagged model triangles while the shapes registry is unlocked, so the ball can ray-cast straight down onto the apron, pad and drawn road at any time
* [Level-horizon camera controller swapped into the main viewport](level-horizon-camera-controller.md) - Subclass KSA's FixedController to supply a rate-limited up vector, re-pose the view inside the viewport pass and take mouse input, installed by a checked reflection write into a get-only backing field
* [Mod log file with rotation and a verbose toggle](mod-log-file-with-rotation.md) - A per-mod log file beside KSA's own logs, truncated each session with the previous session kept as a prev log, batched writes with a flush timer, and a runtime Debug toggle instead of a debug build
* [Mod meshes held by a kitten as cosmetic attachments](kitten-held-props.md) - Hang a mod's own glTF on a kitten bone at runtime by adding it to CharacterAvatar.Attachments.CosmeticAttachments, building the StaticMeshRenderable the way the engine builds Core's, with the material slot filled first and an optional see-through visor-glass technique
* [Packaging, deploy and release pipeline](packaging-and-release.md) - One portable net10.0 archive for Windows and Linux with gates against shipping symbols or game DLLs, a deploy script that installs and registers the mod, and semantic-release plus SpaceDock publishing driven by Conventional Commits
* [Posing kitten bones through the pose-processor list](kitten-pose-processor.md) - Turn, move or stretch any bone of a live EVA kitten by adding an IAnimProcessor to its AnimatedRenderable.AnimProcessors list, reached through one reflection hop to the private avatar
* [Prop and course asset XML](prop-and-course-asset-xml.md) - Declaring a mod's own meshes and PBR materials as standalone GltfFile and PbrMaterial assets, drawn by code instead of being built as parts, static objects or clutter
* [Putting address pose drawn on the kitten skeleton](putting-address-pose.md) - Draw a kitten stepped up to the ball, bent at the waist with both arms aimed at the grip, by carrying the skeleton's root bones in a pose processor while the physics body stays where the player walked it, and place the club against each view's own wrist
* [Putting session with a mouse-swung club](putting-session.md) - The flown kitten carries a putter, drops a ball, steps up to it with G and swings with the mouse, the session tying the drawn pose, the borrowed view, the simulated ball and the strike sound together across the frame
* [Save-load detection](save-load-detection.md) - Detecting that a save was loaded, which StarMap has no hook for and which never leaves the flight scene, with a latched Harmony postfix on Program.OnGameLoaded consumed by the next simulation step
* [Swept contact against a craft's real hull](swept-hull-contact.md) - Analytic swept contact for a fast small body, with a bounding sphere as broad phase and a per-triangle ray cast through Part.RayCastEgo as the narrow phase, falling back to the sphere rather than to a miss
* [Terrain height queries off the engine's height field](terrain-height-queries.md) - How KSAGolf asks the engine where the ground is, through one Celestial height query wrapped as a ground test, a height-field seam, a ridge mask, a slope reading and a local east/north frame, with the sea clamped in
* [Top-down minigolf course builder](minigolf-course-builder.md) - A B-key build mode that turns the main view straight down over a body-fixed course grid, picks the cell under the cursor, snaps a ghost piece onto open ports, and places, moves, removes, undoes and saves pieces while taking the keys and clicks away from the kitten
* [Visual testing captures](visual-testing-captures.md) - Scripted screenshots through KSA's own ScreenshotCapture reached by reflection, with a UI-free warm-up, per-picture JSON manifests carrying the craft's projected screen position, simulated-time series, same-instant variant diffs and a temporal noise map
* [World-positioned sounds](world-positioned-sounds.md) - Shipping wav files as Sound assets in a mod's XML and playing them at an arbitrary world point through GameAudio.PlaySound, anchored on a nearby vehicle for Doppler and air pressure
