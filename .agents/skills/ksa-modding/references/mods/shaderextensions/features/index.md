# Mod Feature

* [Attribute duck typing as an inter-mod API](duck-typed-attribute-api.md) - Consumer mods copy look-alike attribute classes instead of referencing ShaderExtensions; a Program.Main prefix scans every AssemblyLoadContext, matches attributes by full name, closes generic registration methods over the consumer's struct and fills its static delegate fields
* [CI build against private game DLLs with GitHub and SpaceDock releases](ci-build-and-release.md) - GitHub Actions workflow that pulls the latest StarMap and KittenExtensions DLLs from their releases, clones private KSA DLLs with a GitHub App token, builds Debug for PRs and Release for main, and publishes to GitHub and SpaceDock when VersionPrefix changes
* [Cross-pass image references](cross-pass-image-references.md) - PostProcessingInputReference and PostProcessingOutputReference child elements bind the input or output image of another pass, picked by RenderPassId and by pre- or post-ImGui stage, as extra sampler2D bindings so a pass can combine images from earlier in the chain
* [Custom XML asset types and injected child elements](xml-asset-types-and-element-injection.md) - Registers the four asset types through KittenExtensions attributes and runs its own copy of KittenExtensions' XmlAttributeOverrides injector in a Program.Main prefix to add buffer, push constant and pass-reference child elements before any game XML is parsed
* [Mod-defined push constants](push-constants.md) - Another mod declares a small blittable struct as an XML element whose value lives in managed memory, becomes a VkPushConstantRange in the pass pipeline layout and is pushed with vkCmdPushConstants every time the pass is recorded
* [Mod-defined uniform buffer bindings](custom-uniform-buffers.md) - Another mod declares a blittable struct as a new XML element; ShaderExtensions allocates a persistently mapped host-coherent uniform buffer for it, binds it to the ShaderEx fragment shader and fills the struct's static lookup delegates so the mod can write the buffer from C# every frame
* [mod.toml generated by MSBuild with a StarMap dependency](generated-mod-toml.md) - An MSBuild targets file copies the build output into Release/<ModName>/ and writes mod.toml from project properties, including a [[StarMap.ModDependencies]] block whose ModId, Optional flag and ImportedAssemblies come from StarMapModDependency items in the csproj
* [Per-window ImGui post shader](imgui-window-post-shader.md) - <ImGuiShader> re-renders one tagged ImGui window's draw list offscreen with the backend's own shaders, runs a ShaderEx fragment over its bounding rectangle, and swaps the draw list for a single AddImage of the result before the game's ImGui pass
* [Post-ImGui global post shaders on the swapchain image](post-imgui-global-post-shaders.md) - <GlobalPostShader> passes run after the game's swapchain render pass ends, copying the finished swapchain image (scene plus ImGui) into a tracked render target, running the chain on it and copying the result back into the swapchain image before it is presented
* [Pre-ImGui post-processing on the HDR scene image](pre-imgui-post-processing.md) - <PostProcessingShader> passes run on the game's HDR offscreen color image immediately before the swapchain render pass that tonemaps the scene and draws ImGui, then copy their result back into the offscreen image so the game's final composite reads it
* [Rebuilding mod GPU resources with the game renderer](renderer-rebuild-hook.md) - A Program.RebuildRenderer postfix, a forced renderer rebuild on the first rendered frame and a per-frame extent check keep the post-processing chains, their render targets and the shared time buffer in step with swapchain resizes and graphics-setting changes
* [RenderGame transpiler around the swapchain render pass](rendergame-render-pass-transpiler.md) - A Harmony transpiler on Program.RenderGame swaps the swapchain BeginRenderPass call for a static method with the same stack signature that records mod passes first, and inserts a call after the last EndRenderPass, giving the mod two command-recording slots outside any render pass
* [RenderPassId-ordered fullscreen pass chain](post-processing-pass-chain.md) - Builds one render target, RenderTechnique pipeline and descriptor set per post-processing shader, ordered by RenderPassId, where each pass samples the previous image through a sampler2D at set 1 binding 0 and draws a four-vertex strip with dynamic rendering
* [ShaderEx asset with extra descriptor bindings](shaderex-extra-bindings.md) - A ShaderReference subclass registered as the <ShaderEx> XML element that gives a fragment shader extra texture and uniform-buffer bindings by building its own descriptor pool, set layout and writes from the element's children
* [Shared shader time uniform buffer](shared-time-uniform-buffer.md) - One persistently mapped uniform buffer holding frame number, frame delta, real time, simulation time and warp rate, rewritten from a Program.RenderGame prefix every flight frame and bound at binding 1 of every ShaderEx descriptor set
* [Tagging an ImGui window with a draw-list marker callback](imgui-draw-list-marker-callback.md) - A no-op ImDrawList callback whose copied user data carries a marker hash and a shader key lets any mod tag the current ImGui window for a custom shader without referencing ShaderExtensions; the renderer later scans each draw list's commands for that marker
