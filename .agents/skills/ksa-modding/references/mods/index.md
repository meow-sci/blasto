# Subdirectories

* [compendium](compendium/index.md) - Celestial encyclopedia window that joins a cross-mod JSON catalog with the live star-system tree and, through Harmony patches on the navball, gauges and flight computer, lets fixed stars and barycenters act as navigation-only targets
* [gatos](gatos/index.md) - A KSA mod that boots a real Alpine Linux in a QEMU microVM beside the game, exposes live telemetry and controls as a 9P /sim filesystem plus HTTP, MQTT, MCP and serial APIs, and adds programmable camera, paint, decal, audio and physics features on top
* [kitten-engineer-redux](kitten-engineer-redux/index.md) - Small StarMap mod in the spirit of Kerbal Engineer Redux that adds a staging and mass analysis panel to the vehicle editor and a configurable flight HUD with orbit, suicide-burn, planner, alert and telemetry-graph sections, all drawn from Harmony postfixes on the game's own UI methods
* [kittenextensions](kittenextensions/index.md) - Foundational StarMap library mod that runs XPath patches over one combined XML document built from every installed mod's data files and lets other mods register new XML asset types, by redirecting the game's XmlLoader calls and extending its XmlSerializer overrides
* [ksa-advancedflightcomputer](ksa-advancedflightcomputer/index.md) - Maneuver quick-tools, flyby targeting and multi-pass burns in the stock Transfer Planner, RCS-only burns, automatic staging and burn removal, hyperbolic targets, and closed-loop powered guidance for ascent, boostback and landing with native convex solvers
* [ksa-aircrafthud](ksa-aircrafthud/index.md) - Fighter-style head-up display drawn with an ImGui draw list in a fullscreen window, styled by a ShaderExtensions ImGui window shader and backed by a canopy-glass post-process chain, with a custom font, an INI settings file and a ModMenu entry
* [ksa-deltavmap](ksa-deltavmap/index.md) - An auto-generated, interactive delta-v subway map and transfer-window planner that reads every star system of the loaded universe live, prices routes with closed-form patched conics, and adds an opt-in transfer-window overlay to the game's 3D map mode
* [ksa-measuretools](ksa-measuretools/index.md) - Click-to-measure ruler, protractor, surface, circle and face-angle tools for the map view, the flight view and the vehicle editor, with snapping to bodies, disc edges, orbit lines and part geometry down to mesh vertices and feature edges
* [ksa-public-telemetry](ksa-public-telemetry/index.md) - StarMap mod that draws a SpaceX-webcast-style telemetry bar over KSA flight with live gauges, an engine diagram built from real nozzle positions, a mission clock, inferred flight events and planned burns, while hiding and restoring the stock HUD
* [ksacars](ksacars/index.md) - Driveable cars for KSA, a beach buggy and a flying Cadillac Eldorado, built as single parts whose springs, tyres, engine, rockets, lights, sounds and driver animation are simulated by a StarMap code mod and injected into the engine's vehicle step
* [ksaero](ksaero/index.md) - Small StarMap mod that replaces stock atmospheric drag with a body-of-revolution lift and drag model by rewriting one call site in the vehicle force function
* [ksagolf](ksagolf/index.md) - A golf mod foundation for Kitten Space Agency with a working putting game and a minigolf course builder on top of extensive frame-timing, camera, kitten-posing, terrain and developer tooling
* [ksarmory](ksarmory/index.md) - Weapon systems for Kitten Space Agency built as reusable machinery (sensors, fire control, sub-frame projectiles, articulated mounts, a ballistic computer, compute-shader effects) with each weapon a registry entry plus art, bound to the game by six StarMap hooks and six Harmony patches
* [ksastructures](ksastructures/index.md) - A StarMap code mod that stands a walkable office tower on Earth as launch-pad static objects dug into the terrain at load, with a lift, an underground garage lit by shadow-casting lamps, a spiral ramp, a chair and computer that fly the nearest craft, and a first-person kitten view
* [lonelyplanets](lonelyplanets/index.md) - Native reduced-system presets, local celestial assets and starting-vessel situations
* [mpfx](mpfx/index.md) - Small post-processing mod by AMPW that declares a 32-pass color-grading chain as ShaderExtensions XML assets, feeds it from an ImGui settings window each frame and keeps profiles only as hand-copied XML
* [ohmystars](ohmystars/index.md) - StarMap mod that draws constellation lines, names, IAU boundaries and an RA/Dec grid on the sky from Stellarium and AT-HYG data, with a star browser, navball marker, orient-to-star mode and a star field editor
* [purrtty](purrtty/index.md) - In-game terminal emulator for KSA that hosts real shells (ConPTY, POSIX pty, in-game console, other mods' shells) on libghostty-vt and renders them as ImGui windows or as textures on world-space quads
* [realatmospheres](realatmospheres/index.md) - StarMap mod that rebuilds the Sol system's atmospheres, hazes and clouds from measured data by loading patched copies of KSA's shaders and system XML at launch, and swaps in measured flight atmosphere profiles
* [shaderextensions](shaderextensions/index.md) - Shader infrastructure mod adding XML-declared fragment shaders with extra texture, uniform-buffer and push-constant bindings, per-window ImGui shaders, and RenderPassId-ordered post-processing chains before and after the ImGui pass via a Program.RenderGame transpiler
* [starmap](starmap/index.md) - The community code-mod loader for KSA, which launches the game in its own process, loads each mod's DLL into an isolated AssemblyLoadContext, resolves mod dependencies, and calls mods back at seven lifecycle points through Harmony patches
* [unscience](unscience/index.md) - A meow-sci monorepo supermod that bundles 31 feature sub-mods (welding, scaling, decals, plumes, rings, cameras, kittens, saves and more) behind one StarMap entry class, one Harmony instance and one ImGui toolbox
