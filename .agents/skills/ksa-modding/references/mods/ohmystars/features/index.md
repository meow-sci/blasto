# Mod Feature

* [AT-HYG star catalog and star information](hyg-star-catalog.md) - Parse the 330k-row AT-HYG CSV into Hipparcos-keyed ecliptic directions and star records, special-case the central star, and browse stars by constellation, proper name or Bayer designation in an ImGui tab
* [Attitude-mode hand-off patches](attitude-mode-handoff-patches.md) - Detect every stock path that changes attitude mode with Harmony prefixes on flight computer, vehicle, kitten and MMU methods so a mod-owned custom target is released and the shared rate command restored
* [Constellation lines and labels on the sky](sky-overlay-lines-and-labels.md) - Convert J2000 RA/Dec to the game ecliptic frame, place points on the camera-centred 19.5-unit star sphere, project with Camera.EgoToScreen and draw lines and labels into a transparent full-screen ImGui window from StarMapAfterGui
* [Game-styled popups and toasts](game-styled-popups-and-toasts.md) - Show KSA-styled modal confirmations by subclassing the game's Popup class, which self-registers for Popup.DrawAll, and give feedback with TimedAlert toasts
* [Mod root and packaging](mod-root-and-packaging.md) - Resolve the mod folder from the running assembly location, ship data beside the DLL with an overridable game path and an explicit deploy target, and rely on StarMap default entry-assembly resolution
* [ModMenu entry and game-styled windows](modmenu-entry-and-console-style-windows.md) - Register an Oh My Stars submenu through the ModMenuEntry attribute and draw resizable windows with the game ConsoleStyle and ConsoleWidgets look while keeping ImGui saved geometry
* [Navball star marker](navball-star-marker.md) - Reproduce NavBallRenderer.ToScreenMarker and the NavballMarkers.glsl styling in C# to paint a custom star marker, rim arrow and label on the stock navball through the ImGui foreground draw list
* [Occlusion by bodies](overlay-occlusion-by-bodies.md) - Hide sky-overlay points behind planets, moons, the star and vehicles with a per-frame CPU ray-sphere test against every body and body-orbiting vehicle of the camera's current system
* [Orient a vessel to a star](orient-to-star.md) - Point a vessel or kitten at a star by writing a Custom EclBody attitude target to the stock flight computer and re-applying it in a Vehicle.PrepareWorker prefix just before the physics snapshot
* [RA/Dec grid](ra-dec-grid.md) - Draw a celestial right ascension and declination grid as 1-degree arcs with a clip-space near-frustum cull and overlap-free chart labels on the same star sphere as the constellations
* [Save-scoped settings sidecar](save-scoped-settings-sidecar.md) - Postfix UncompressedSave.Load and Make to track the current save and write an atomic per-save settings file into the save folder (vestigial in this version)
* [settings.ini persistence](ini-settings-persistence.md) - Persist every overlay and window option as key=value lines in a settings.ini beside the DLL, saving on each change and every frame the window open state differs, while ImGui keeps window geometry
* [Star binary switcher](star-binary-switcher.md) - Discover star binary files, rewrite Mod.StarBinaries by reflection and reload the instanced star field at runtime with capacity-aware sampling, named presets and game-styled confirmation popups
* [Star instance restyle patch](star-instance-restyle-patch.md) - Restyle every background star by prefixing InstancedStarTechnique.AddInstance to rewrite its size and colour bytes, and resize the instance buffer at runtime by reflecting into the technique
* [Star pointer](star-pointer.md) - Draw a line from the mod window to the selected star, pushing off-screen and behind-camera targets to the screen edge through the clip-space direction
* [Stellarium sky cultures](stellarium-sky-cultures.md) - Load 53 legacy Stellarium sky cultures from constellationship.fab and constellation_names files, switch between them at runtime, and keep only segments whose stars match the stock star binary bit for bit
