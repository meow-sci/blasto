# Mod

* [KSArmory](overview.md) - Weapon systems for Kitten Space Agency built as reusable machinery (sensors, fire control, sub-frame projectiles, articulated mounts, a ballistic computer, compute-shader effects) with each weapon a registry entry plus art, bound to the game by six StarMap hooks and six Harmony patches
