# Game Feature

* [Patching private and overloaded game methods by name](overview.md) - How a Harmony patch attaches to a private, protected or overloaded KSA method that cannot be written with typeof or nameof, with string names, manual lookups, explicit parameter arrays, TargetMethods and injected fields, and how each fails when the target moves

# How-To

* [Attribute argument types that bind by assignability](patch-a-private-game-method-by-name-4.md) - List the parameter types in a HarmonyPatch attribute and let Harmony bind them by assignability, as Compendium's IGameViewport entry binds to the IViewport overload of Astronomical.ShouldDrawLines, and list the exact type so a new overload cannot change the target
* [Explicit parameter arrays with MakeByRefType for overloaded and by-reference targets](patch-a-private-game-method-by-name-3.md) - Pick one overload out of several same-named game methods by passing the full parameter list to AccessTools.Method, writing every in, ref and out parameter as Type.MakeByRefType(), so the lookup is neither ambiguous nor fooled by a later overload
* [HarmonyPatch attribute with a string method name, applied by PatchAll](patch-a-private-game-method-by-name-1.md) - Hook the private Program.OnFrameEditor, which runs every flight frame even with the HUD hidden, with a [HarmonyPatch("OnFrameEditor")] postfix on a [HarmonyPatch(typeof(Program))] class whose parameter is named like the target's so Harmony passes the frame delta
* [Manual AccessTools lookup with a degrade path when the method is gone](patch-a-private-game-method-by-name-2.md) - Look up the private Program.OnFrameCelestials by name with AccessTools.Method; a null result records a Trouble string and logs the consequence while another hook keeps the mod working, and the patch class stays installable even if the target is absent
* [Prefer __instance and a public member over a field injector that matches nothing](patch-a-private-game-method-by-name-7.md) - Hook the Orbit and Fly controllers' OnFrame with one prefix that reads the camera from the public Controller.Camera through __instance, after a ___Transform field injector that matched no field made Harmony throw and abort the supermod's remaining patches
* [Reading a private instance field with a triple-underscore parameter](patch-a-private-game-method-by-name-6.md) - Postfix the private GroundClutterPlacementData.PopulateLaunchPadExclusionZones with a ref zones array and a Celestial ____celestial parameter that Harmony fills from the private _celestial field, installed by name with a logged fallback when the method is gone
* [TargetMethods with per-name AccessTools lookups and the __args array](patch-a-private-game-method-by-name-5.md) - Patch several private static game methods in one class by yielding each AccessTools.Method lookup from TargetMethods and reading the argument you need from the object[] __args, so a prefix needs no knowledge of the parameter types it cannot name
