# Mod

* [unscience](overview.md) - A meow-sci monorepo supermod that bundles 31 feature sub-mods (welding, scaling, decals, plumes, rings, cameras, kittens, saves and more) behind one StarMap entry class, one Harmony instance and one ImGui toolbox

# Subdirectories

* [features](features/index.md) - Reusable features of unscience with code references
* [submods](submods/index.md) - The sub-mods of the unscience supermod, each linking its features
