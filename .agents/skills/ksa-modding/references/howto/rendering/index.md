# Subdirectories

* [lights-and-particles](lights-and-particles/index.md) - Lights, particles, explosions and exhaust plumes submitted through the engine's own systems.
* [meshes](meshes/index.md) - Drawing and hiding geometry through the engine's own renderers: mod meshes, GPU buffer headroom, shadow casters, hidden parts and distance culling.
* [overlays](overlays/index.md) - Projecting world and sky points to the screen and drawing overlays that stay glued to bodies, craft and the sky.
* [textures-and-decals](textures-and-decals/index.md) - Getting pixels onto the screen and onto surfaces: texture upload, ImGui images, replacing game textures, UI rendered to textures, world quads, projected decals and part recolouring.
* [vulkan-passes](vulkan-passes/index.md) - Recording your own Vulkan work inside KSA's frame: command submission, pass insertion, compatible pipelines, HDR compute passes, renderer rebuilds, resource teardown and frame capture.
