# Mod

* [KSACars (Fast & Purrious)](overview.md) - Driveable cars for KSA, a beach buggy and a flying Cadillac Eldorado, built as single parts whose springs, tyres, engine, rockets, lights, sounds and driver animation are simulated by a StarMap code mod and injected into the engine's vehicle step
