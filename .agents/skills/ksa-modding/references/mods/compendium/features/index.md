# Mod Feature

* [Atmosphere density and pressure graphs](atmosphere-profile-graph.md) - A secondary ImGui window samples a body's physical atmosphere model at 101 altitudes every frame and plots density and pressure curves with grid, axis labels and a draggable altitude marker on the window draw list, with six pressure units
* [Body statistics derived from live game data](derived-body-properties.md) - On the first UI frame after a universe loads, Compendium matches its JSON entries to live bodies and computes mass, gravity, escape velocity, tilt, inclination, periods, axes, sphere of influence and atmosphere strings from game data
* [Celestial compendium window](celestial-info-window.md) - A two-pane ImGui window drawn from StarMapAfterGui that joins JSON category data with the live body tree of the selected star system, with category buttons, collapsible body lists, a draggable splitter, per-view side pane, a star-system combo with search and a vessel picker
* [Closest approach to a root target](root-closest-approach-search.md) - A Program.UpdateGauges postfix fills the TGT readouts for a root target, estimating closest approach by sampling and golden-section refinement over 10 game years of coast flight-plan patches, refreshed at most once per real second
* [Cross-mod JSON catalog](cross-mod-json-catalog.md) - At immediate load Compendium reads every JSON file in the mod folders beside its own that carries the CompendiumJson marker, keys entries by system or root prefix and body path, and lets other mods' entries override its defaults
* [Custom fonts in the ImGui atlas](custom-fonts-in-imgui.md) - Every .ttf and .otf in the mod's Fonts folder is added to the shared ImGui font atlas at immediate load, and the window pushes the chosen face at a user-set base size times a per-section scale with ImGui 1.92's sized PushFont, balancing pushes with a counter
* [Flight-computer attitude tracking against a root target](flight-computer-root-attitude-tracking.md) - A prefix and finalizer on FlightComputer.ComputeControl inject a synthesized NavigationTarget into the solver thread's navigation struct for the duration of one call, so the stock attitude controller runs Toward, Away and TGT-frame rotation hold against a target that has no orbit
* [Local decompiled game source refreshed with ilspycmd](decompiled-source-refresh.md) - A PowerShell script decompiles selected game assemblies with ilspycmd into a gitignored decompiled folder and records the game version, and the repository's assistant instructions point code assistants at that tree instead of running ILSpy per lookup
* [Logo image as an ImGui texture](logo-image-as-imgui-texture.md) - At immediate load the mod decodes a PNG with the game's texture loader, uploads it as a SimpleVkTexture through a staging pool that submits and waits on dispose, registers the image view with the game's ImGui Vulkan backend and draws it with ImGui.Image, keeping it for the whole session
* [ModMenu entry that toggles the window](modmenu-window-toggle.md) - A static method tagged [ModMenuEntry("Compendium Window")] from the bundled ModMenu.Attributes.dll draws a MenuItem that flips the window flag, giving ModMenu users a menu-bar toggle while the mod itself needs only the small attributes assembly
* [Navball target marker and TGT frame for a target without an orbit](navball-target-marker-and-tgt-frame.md) - Transpilers swap the navball's NavigationTarget.Create call for a mod method and make four Target null tests see the navigation-only target, so the TGT marker, TGT navball mode, gauge panel and TGT frame work for a fixed star or barycenter
* [Navigation-only root targets](root-navigation-targets.md) - Lets a vehicle target a fixed star or root barycenter, which the game cannot target, by keeping a session-only side table keyed by the vehicle and its burn plan and applying UI requests from a prefix on InputEvents.ApplyInputEvents
* [Orbit line visibility and color](orbit-line-visibility-and-color.md) - A postfix on Astronomical.ShouldDrawLines forces or suppresses a body's orbit line from a mod-side Always/On/Off table, and color pickers write Orbit.OrbitLineColor directly, applied to one body, its moons, an orbit group, a category or the whole system
* [Pointer lines to the selected body](body-pointer-overlay.md) - A full-viewport, input-transparent ImGui window draws one or two lines from the nearest corners of the Compendium window to the selected body's screen position, or to the screen edge in its direction when it is off screen, using the main camera's ego-to-screen and ego-to-clip projections
* [settings.ini persistence](settings-ini-persistence.md) - A hand-rolled key=value INI next to the DLL stores whether the window is open and the pointer options, loaded first at immediate load and rewritten whenever a value changes, including a per-frame comparison that catches both the ModMenu toggle and the window's close button
* [Star systems and the body tree](star-systems-and-body-tree.md) - How Compendium finds every star system through Universe.Roots, walks IParentBody.Children to collect bodies and stars, names bodies by dotted parent paths, and keeps its own selected system instead of following Universe.WorldSun
* [Target orbiting bodies through the game's settarget command](native-target-selection.md) - The window's Select as Target button calls Universe.SetTargetCommand and UnsetTargetCommand, the same terminal actions the game's Target Track window uses, which validate the ids and queue an InputEvents.ChangeTargetData that reaches Universe.SetTarget at the frame's input point
