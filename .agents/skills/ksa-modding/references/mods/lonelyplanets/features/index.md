# Mod Feature

* [Dummy companion body](dummy-companion-body.md) - A locally defined atmospheric body with tiny height data is loaded beside three stock-planet presets
* [Planet starting situations](planet-starting-situations.md) - Custom Situation assets place the stock Gemini7 vessel in a chosen orbit around each planet
* [Single-planet system presets](single-planet-system-presets.md) - Three native System XML files select Sol and one stock planet as a smaller playable system
