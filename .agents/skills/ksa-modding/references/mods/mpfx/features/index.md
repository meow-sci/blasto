# Mod Feature

* [Color grading shader math](color-grading-math.md) - Reusable grading formulas from MPFX's shaders: lift, gamma and gain in a mat4 with an on/off flag, a 1000 to 40000 K temperature tint with luminance preservation, YIQ hue rotation, mid-gray HDR contrast, Rec. 709 saturation, overlay and an aspect-corrected vignette
* [Effect chain declared as RenderPassId-ordered post-process assets](effect-chain-assets.md) - MPFX declares its whole effect stack in one XML asset file as 16 PostProcessingShader (pre-ImGui) and 16 GlobalPostShader (post-ImGui) elements with RenderPassId 128 to 143, sharing parameter buffers between the two sides by Id
* [Effect profiles as XML assets with clipboard export](xml-effect-profiles.md) - MPFXProfile is a KittenExtensions KxAsset type, so profiles load from any mod's asset XML, while profiles created in game live only in memory and the Export tab serializes the current one with XmlSerializer, DefaultValue and ShouldSerialize trimming, for the user to paste into an asset file by hand
* [Effect settings window and ModMenu entry](effect-settings-window.md) - One ImGui window with button-driven tabs, a three-column table of collapsing headers per effect with pre/post ImGui rows, a reusable slider-plus-input row helper, color pickers and per-row Reset buttons, opened from a ModMenu attribute entry
* [Film grain and experimental effects](film-grain-and-experimental-effects.md) - Animated film grain driven by a per-side push-constant clock that can follow time warp, built on Ashima/Gustavson GLSL noise with soft-light blending and luminance falloff, plus the self-described experimental RGB2HSV, HSV2RGB and SingleColor passes kept under a Fun stuff header
* [Generated mod.toml and CI release pipeline](ci-release-pipeline.md) - MSBuild items generate mod.toml with the assets array and StarMap ModDependencies on every build, and a GitHub Actions workflow builds against KSA DLLs from a private repo via a GitHub App token, then publishes GitHub and SpaceDock releases
* [Per-frame effect parameter upload](per-frame-parameter-upload.md) - From StarMapAfterGui, MPFX writes film grain time into push constants every frame the HUD is shown and rewrites every effect uniform buffer through ShaderExtensions span lookups only when a dirty flag set by the settings window is raised, substituting neutral values for disabled effects
* [Separable Gaussian blur with CPU-computed weights](separable-gaussian-blur.md) - A two-pass horizontal and vertical Gaussian blur where C# computes normalized one-sided weights for a radius up to 20 and packs them into a std140 int-plus-vec4[6] uniform block, one shader file serving both chains through different buffer Ids
* [Shader contract for chain passes](effect-shader-contract.md) - Each MPFX fragment shader follows the ShaderExtensions pass contract, with the previous pass as sampler2D at set 1 binding 0, ShaderTime at binding 1, one parameter block at binding 2 and an optional push constant, and returns its input when parameters are neutral
* [Uniform buffer and push constant structs bound by attribute name](duck-typed-buffer-structs.md) - MPFX tags blittable structs with private copies of ShaderExtensions' SxUniformBuffer and SxPushConstant attributes, and ShaderExtensions finds them by name, registers XML elements and fills their static lookup delegates, so MPFX never references ShaderExtensions.dll
