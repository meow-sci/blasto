# Mod Feature

* [Custom stage delta-v estimator](custom-stage-delta-v-estimator.md) - A self-contained per-stage rocket-equation estimate that walks staging sequences, subtracts decoupled subtrees, sums engine thrust at a chosen ambient pressure and claims each reachable tank once through the resource manager's consumption order
* [Draw-list line graph](draw-list-line-graph.md) - A self-contained time-series chart drawn entirely with ImDrawList primitives, with nice-number axis ticks, a time axis, area fill, min/max/now markers, a dashed alert threshold line and a hover crosshair tooltip, without ImPlot
* [Draw-list widget kit with pop-out sections](draw-list-widget-kit.md) - A small immediate-mode widget library that lays out rows, tiles, gauges, toggles and buttons by hand on the window draw list with InvisibleButton hit-testing and a running y cursor, plus collapsible sections that can be popped out into their own ImGui windows and docked back
* [Editor panel injected into the vehicle editor](editor-panel-injection.md) - A Harmony postfix on VehicleEditor.OnDrawUi draws a KER-style analysis window every editor frame, reading the craft under construction from EditingSpace.Parts and the home body's gravity and atmosphere
* [Flight HUD on the controlled vehicle](flight-hud-controlled-vehicle-postfix.md) - A Harmony postfix on Vehicle.OnDrawUi, filtered to the controlled vehicle in the main viewport, gathers orbit, thrust, TWR, mass, acceleration and staging data once per frame into a shared frame record and draws a sectioned ImGui HUD from it
* [HUD stat tiles and threshold alerts](hud-widgets-and-threshold-alerts.md) - A player-ordered set of up to nine stat tiles and twelve threshold alert rules evaluated against one per-frame context record, surfaced as a warning banner, outlined tiles, warning-coloured rows and a dashed threshold line on the history graph
* [JSON settings with autosave](json-settings-autosave.md) - Lazily loads a System.Text.Json settings file from Documents on the first UI frame and re-serialises the live static state at most every two seconds, writing only when the JSON text changed, with late-registered UI sections picking up their saved state on construction
* [Live and rated engine thrust with TWR](live-engine-thrust-and-twr.md) - Reads actual thrust and mass flow from the applied rocket-nozzle states of active engines, rated full-throttle thrust at an ambient pressure from RocketControllerData or Vehicle.ComputeActiveThrust, and turns both into TWR against gravity computed for any body and altitude
* [Minimal mod.toml, post-build deploy and release zip](dist-zip-and-post-build-deploy.md) - Ships a one-line mod.toml that relies on StarMap's default entry assembly, copies the mod DLL and the ModMenu attribute DLL into the mods folder after each build, and commits a three-file release zip under dist/
* [ModMenu entry with a standalone menu fallback](modmenu-entry-with-standalone-fallback.md) - Registers a "Kitten Engineer Redux" menu with ModMenu through the attribute's active-flag property and, when ModMenu does not claim it, draws the same toggles itself from a postfix on the game's empty Program.DrawProgramMenusHook
* [Native stage performance readout](native-stage-performance-readout.md) - Reads per-stage delta-v, thrust, Isp and masses from the game's own staging simulator (PartTree.PerformanceSequences), derives burn time and max TWR from its burn phases, and falls back to a custom estimate while the cache is dirty
* [Orbit readouts and Hohmann estimate](orbit-readouts-and-hohmann-estimate.md) - Derives apsis altitudes, period, apsis and node countdowns, eccentricity vector, orbit normal, vertical and horizontal surface speed and latitude/longitude from the vehicle's Orbit, and estimates a coplanar Hohmann transfer to a target circular altitude
* [Suicide-burn calculator](suicide-burn-calculator.md) - Estimates the altitude, duration and countdown for a last-moment full-thrust landing burn from radar altitude, surface-relative velocity, active-engine thrust at the live ambient pressure and an averaged gravity term
* [Telemetry history and CSV export](telemetry-history-and-csv-export.md) - Samples six flight metrics every 0.25 s of wall-clock player time into fixed 720-entry arrays from the HUD draw, resets on vehicle change, and writes the window to a timestamped CSV under the mod's Documents data folder
