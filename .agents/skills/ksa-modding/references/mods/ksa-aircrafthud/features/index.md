# Mod Feature

* [Always-on ImGui hook from a Program.OnFrameEditor postfix](always-on-onframeeditor-hook.md) - Patches the private Program.OnFrameEditor with a Harmony postfix to get the earliest point of every flight frame's ImGui frame, one that still runs when the player hides the UI and that StarMap's own GUI hooks do not offer
* [Canopy-glass post-process chain](glass-post-process-chain.md) - Three ShaderExtensions PostProcessingShader passes (refracted two-pass Gaussian blur, then a composite with chromatic aberration, edge blur, glowing dirt and grain) that make the IVA scene look as if seen through a canopy
* [Curved, chromatic HUD window via an ImGuiShader](imgui-window-hud-shader.md) - Tags the HUD's ImGui draw list with a ShaderExtensions marker callback so the window is rendered offscreen and re-composited through UI_PP_HUD.frag, which barrel-curves it and adds luminance-masked chromatic aberration in IVA view
* [Custom TTF font in the ImGui atlas](custom-hud-font.md) - Adds a bundled TTF from the mod folder straight to ImGui's font atlas at StarMapImmediateLoad, then draws at several sizes from that single font with ImGui 1.92's PushFont(font, size), bypassing KSA's FontManager
* [Fullscreen draw-list HUD](fullscreen-drawlist-hud.md) - Draws a complete fighter HUD (pitch ladder, horizon, flight path marker, heading tape, speed and altitude tapes) as ImGui draw-list geometry in an input-less fullscreen window from a Harmony postfix on Program.OnFrameEditor
* [INI settings file and settings window](ini-settings-and-settings-window.md) - Keeps HUD options in a hand-parsed hud.ini next to the mod DLL, loads it at StarMapImmediateLoad, and edits it from an ImGui settings window drawn in StarMapBeforeGui with toggles, unit menus, color pickers, scale sliders and an explicit save button
* [ModMenu entry with a vendored attributes DLL](modmenu-entry-vendored-attributes.md) - Lists the mod in the community ModMenu through a static method tagged [ModMenuEntry("Aircraft HUD")], compiling against a ModMenu.Attributes.dll committed to the repo and shipping that DLL next to the mod so StarMap's per-mod load context resolves it
* [Props-based build straight into the mods folder](props-based-build.md) - Splits machine-specific build settings into an imported AircraftHUD.props that references the game DLLs by wildcard with Private=False, pulls StarMap.API and Harmony from NuGet, and sets OutputPath to the user's KSA mods folder so every build is a deploy
* [ShaderExtensions push constants and uniform buffers from C#](sx-push-constants-and-buffers.md) - Declares ShaderExtensions' marker attributes locally in the ShaderExtensions namespace so the framework discovers the mod's buffer structs by name, gets lookup delegates injected into static fields, and writes an enabled flag and time value into three per-pass push constants each frame
* [Spatiotemporal blue-noise dithering](blue-noise-dithering.md) - Samples a 64-slice spatiotemporal blue-noise (STBN) texture stacked into a 128x8192 PNG, picking the slice from a C#-supplied time value, to add per-pixel, per-frame grain that hides banding in the post-processed image
* [Surface attitude and air data from the controlled vehicle](flight-data-from-vehicle.md) - Computes HUD flight data on the main thread each frame from the controlled Vehicle, including roll/pitch/heading in the local ENU frame, angle of attack and sideslip, vertical speed, g-load, Mach from the body atmosphere, and radar or barometric altitude
