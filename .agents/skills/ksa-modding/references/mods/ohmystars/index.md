# Mod

* [Oh My Stars](overview.md) - StarMap mod that draws constellation lines, names, IAU boundaries and an RA/Dec grid on the sky from Stellarium and AT-HYG data, with a star browser, navball marker, orient-to-star mode and a star field editor

# Subdirectories

* [features](features/index.md) - Reusable features of Oh My Stars with code references
