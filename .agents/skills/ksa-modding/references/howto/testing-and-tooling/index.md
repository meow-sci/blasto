# Subdirectories

* [game-updates](game-updates/index.md) - Living with a game that changes under you: decompiled references, API-surface tracking, pinned builds and a repeatable upgrade procedure.
* [in-game-testing](in-game-testing/index.md) - Testing and measuring inside a running game: file command bridges, screenshots and visual regression, unattended scenarios, live tuning and per-frame cost.
* [offline-tests](offline-tests/index.md) - Tests that run without a live game session: game-free unit tests, headless simulation rigs, HeadlessHarness suites, patch tests, solver harnesses and one check script for hooks and CI.
