# Subdirectories

* [harmony](harmony/index.md) - Everyday Harmony technique against KSA: skipping prefixes, finalizers, sharing a method with other mods and patching code that runs off the main thread.
* [internals](internals/index.md) - Reaching what the game does not expose: private members through reflection and delegates, private or overloaded patch targets, and methods the JIT inlines.
* [safety](safety/index.md) - Keeping patches survivable across game updates and other mods: refusing and rolling back, isolating failures, validating targets and removing patches cleanly.
* [transpilers](transpilers/index.md) - Changing a game method's IL: the transpiler recipe, swapping one call, finding the right call among several and inserting at an anchor.
