# How-To

* [AccessTools static field refs bound once, replay stock's writes](call-private-game-members-through-reflection-and-delegates-1.md) - Bind the Transfer Planner's private static fields with AccessTools.StaticFieldRefAccess and its private SetTransferInfo as an Action delegate once at class initialisation, then replay the writes stock performs in the order it performs them, with no Harmony patch at all
* [AccessTools.MethodDelegate with a delegate type that mirrors in and ref modifiers](call-private-game-members-through-reflection-and-delegates-4.md) - Call the private static AggressiveInlining PhysicsStates.ComputeDrag from worker threads through an immutable delegate whose type repeats the in and ref modifiers, resolved with an explicit parameter array and bound before the transpiler is installed
* [Copied injector in a consumer mod with the same accessor](call-private-game-members-through-reflection-and-delegates-7.md) - A consumer that cannot reference KittenExtensions copies the XML element injector into its own namespace, adds child element types to existing XML list members through XmlHelper.AttributeOverrides keyed by the declaring type, rebuilds the serializers and swaps the save serializers the same way
* [Delegates over private editor helpers reused in a replacement drag](call-private-game-members-through-reflection-and-delegates-5.md) - A per-axis scale drag replaces VehicleEditor.UpdateSelectedScale but keeps the game's own private QuantizeScale, ScaleBoundsFor and ForEachPartWithSymmetry by binding them as delegates, including the null check on bind and the delegate shapes for a tuple return and a nested Action
* [Plain GetField on internal registries and a generic holder for instance fields](call-private-game-members-through-reflection-and-delegates-2.md) - Reach KSA's internal static registries on ModLibrary with a plain GetField and a typed cast, and probe the private _collection dictionary of SerializedCollection<T> once per closed generic type in a static generic holder, to unregister entries the game offers no API to remove
* [Typed FieldRefAccess, boxed private enum members and by-ref lookups](call-private-game-members-through-reflection-and-delegates-3.md) - Use AccessTools.StaticFieldRefAccess for static fields and FieldRefAccess<T,F> for instance fields of reference types, compare a private nested enum member as a boxed value resolved once from the field's FieldType, and express by-ref parameters with MakeByRefType
* [UnsafeAccessor StaticField on the k__BackingField with UnsafeAccessorType](call-private-game-members-through-reflection-and-delegates-6.md) - Overwrite the get-only statics GameSaves.UniverseSerializer and VehicleSerializer through UnsafeAccessor on their compiler-generated backing fields, naming the game type by string with UnsafeAccessorType
