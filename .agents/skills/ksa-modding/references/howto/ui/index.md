# Subdirectories

* [draw-lists](draw-lists/index.md) - Custom drawing inside windows with ImDrawList: charts, widgets, text grids, canvases, diagrams and fonts.
* [input](input/index.md) - Mouse and keyboard: cursor rays and picking, grid placement, sharing input between ImGui, mod tools and the game, hotkeys and text entry.
* [menus](menus/index.md) - Getting into the game's own UI: the menu bar, ModMenu with and without a hard dependency, injecting into stock windows and menus, and cockpit gauges.
* [overlays](overlays/index.md) - Full-screen overlays and HUDs: choosing the draw list, staying visible and stepping when the HUD is hidden, and instrument-style HUD drawing.
* [windows](windows/index.md) - Mod windows that look and behave like the game's: ImGuiWindow subclasses, stock styling, tabs, settings panels, searchable lists, live data, alerts and loading-time dialogs.
