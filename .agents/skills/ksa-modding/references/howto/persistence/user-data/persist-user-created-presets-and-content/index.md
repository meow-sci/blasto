# Game Feature

* [Persist user-created palettes, presets and content files](overview.md) - Store what the player creates rather than what the mod configures - named color palettes, theme files, override-only color tables, exported XML presets, versioned layout files anchored to a body, and imported media copied into a catalog folder

# How-To

* [Export effect presets as trimmed XML and load them back as a mod's own asset type](persist-user-created-presets-and-content-4.md) - Define a preset as a data-only SerializedId asset with public fields, register it in OnDataLoad so any mod's asset XML can ship one, and export the live settings through XmlSerializer trimmed by DefaultValue and ShouldSerialize methods so the pasted XML contains only what the player changed
* [Import user files into a catalog folder and refer to them by name](persist-user-created-presets-and-content-6.md) - Copy PNG, GLB or sound files the player picks into a mod-owned catalog folder with an import size cap and (n) suffixes instead of overwriting, validate catalog names so they cannot escape the folder, and let features store only the catalog name so a saved scene can reproduce the file
* [Keep named, editable color palettes in a sectioned file with a ColorEdit4 round trip](persist-user-created-presets-and-content-1.md) - Store shipped and user-made palettes of byte colors under one active index, edit them through float4 ColorEdit4 widgets without drift, derive related shades from one picker, and restore the shipped set by name without touching custom palettes
* [Load bundled and user color themes from TOML files and let the user's theme win a name clash](persist-user-created-presets-and-content-2.md) - Merge a code-built default, a read-only bundled folder and a user folder of alacritty-format TOML themes into one catalog, save the player's current look as a named theme with a display name stored in the file, and expand 16 ANSI colors into the 256-color palette
* [Save a user-built layout as a versioned snake_case JSON file anchored to a body by latitude and longitude](persist-user-created-presets-and-content-5.md) - Write each user-built layout as its own indented JSON document with a version, stable piece ids, and a position stored as latitude, longitude, heading and height above the ground, then reload it tolerantly by dropping unknown ids, refusing newer versions and warning when the terrain has moved
* [Store only the colors a player changed, keyed by field name, in the main config](persist-user-created-presets-and-content-3.md) - Keep a mod's whole color scheme as public static fields, find them by reflection, and write only the values that differ from the compiled defaults as
