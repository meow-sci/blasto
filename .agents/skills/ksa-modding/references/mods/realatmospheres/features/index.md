# Mod Feature

* [Anchor-verified text patching of the shadow tree](shadow-tree-anchor-patching.md) - Every edit to the copied shaders and XML is a stock-text anchor with an exact expected count, applied all-or-nothing per file, skipped if its marker is present, and logged and skipped when a game update moves it
* [Atmosphere uniform side channel](atmosphere-uniform-side-channel.md) - Prefix and postfix around AtmosphereRenderer.FillPlanetAtmosphereData put the sim clock, a feature switch and a spin axis into unused fields of the stock atmosphere uniform data, and invalidate kept LUTs
* [Cloud face lighting](cloud-face-lighting.md) - Lights an optically thick volumetric cloud step where its first optical depth ends, found by bisection, and adds a short self-shadow march, so dense decks keep their brightness from any distance
* [Cloud layers in the system XML](cloud-layers-in-system-xml.md) - Inserts templated volumetric cloud decks with masks and flowmaps for the giants, rebuilds Venus's and Jupiter's decks, adds Mars cirrus and Titan hazes, and derives each layer's light-march distance from its geometry
* [Cloud pass shading and ring shadows](cloud-pass-shading-and-ring-shadows.md) - Shader patches to the 2D cloud pass (terminator fade, map-coloured skylight, opaque Venus shell, thin Triton shell), a column-limited thin-cloud ground shadow, and ring shadows added to both cloud passes
* [Core XML entry redirect](core-xml-entry-redirect.md) - Harmony prefixes on four KSA.Mod loader methods swap the Core mod's Astronomicals.xml and Sol template entries for absolute paths to patched copies, so the game's own loaders read the copies
* [Haze-band sky march](haze-band-sky-march.md) - Drifting haze bands for Titan, Pluto and Triton, baked into the LUT density as shells for thin hazes and added to sky pixels by a per-pixel raymarch blended in only where a band could be visible
* [Measured density tables in the atmosphere shaders](measured-density-tables-in-shaders.md) - Rewrites the six exponential density evaluations in KSA's atmosphere shaders to one injected function that reads generated per-body ln-density tables keyed by radius and scale height
* [Measured flight atmospheres](measured-flight-atmospheres.md) - Prefixes on PhysicalAtmosphereReference's density and pressure functions return measured profiles for ten bodies, attached per atmosphere in a ConditionalWeakTable at load, with the boundary height moved to match
* [Measured-atmosphere code generator](measured-atmosphere-generator.md) - Offline Python that builds measured density and pressure profiles for ten bodies, applies KSA's boundary thresholds and emits one C# file of flight tables, XML values and GLSL tables, plus a numpy renderer port
* [Mie phase sentinel dispatch](mie-phase-sentinel-dispatch.md) - Replaces MiePhaseFunction with a dispatcher that treats out-of-range XML asymmetry values as flags, selecting a Mie-theory Mars dust phase (fit or GLSL LUT) or a two-part Pluto haze phase without new uniforms
* [ModMenu page and TOML settings](modmenu-page-and-toml-settings.md) - A ModMenu page found through a vendored attribute, drawn with ImGui calls emitted as DynamicMethods because ImString is a ref struct, and persisted to a hand-parsed settings.toml
* [Nearby-body choice transpiler](nearby-body-transpiler.md) - A Harmony transpiler rewrites the comparison in CelestialSystem.GetNearbyAstronomical so a body within 25 of its radii ranks first, stopping a passing small moon from stealing its planet's detailed render
* [Per-body atmosphere optics in the system XML](atmosphere-optics-in-system-xml.md) - Rewrites Rayleigh, Mie and ozone values for ten bodies from generated physics, promotes Pluto and Triton to AtmosphericBody, and repurposes the ozone slot and scale heights as absorbers and shader keys
* [Reflection-only mod build](reflection-only-mod-build.md) - Compiles against StarMap.API and 0Harmony only, reaches every game member by name through AccessTools, checks each target's shape before patching, and degrades one subsystem at a time when the game changes
* [Release packaging and deploy scripts](release-packaging-and-deploy.md) - Two PowerShell scripts sharing one asset list build the mod and either install it into the active game instance or package a release zip whose entries extract correctly on Linux
* [Relief-softened terminator](relief-softened-terminator.md) - Replaces the planet's self-shadow on its terrain and ground clutter with a horizon test that closes over a band set by the body's maximum relief, removing the knife-edge terminator on airless and thin-air bodies
* [Shader file redirect into a patched shadow tree](shader-file-redirect.md) - A Harmony prefix on RenderCore.ShaderModuleUtils.FromFile points every Content/Core/Shaders path at a patched full copy of the tree in the mod folder, so stock shaders and their includes compile from the copy
* [Shared shadow for two cooperating mods](cross-mod-shared-shadow.md) - Two sibling mods that edit the same Core XML files write into one shared copy, serialized by a global named mutex and reset to stock exactly once per game process by a launch token
* [Texture and phase asset scripts](texture-and-phase-asset-scripts.md) - Python scripts build every shipped asset (cloud masks, flowmaps, cubemaps, modified stock textures and a Mie phase LUT emitted as GLSL) from source maps, game textures and Mie theory
* [Volumetric cloud map flow and faint-cloud lift](volumetric-cloud-map-flow-and-lift.md) - Two CloudFunctions.glsl patches that keep volumetric clouds consistent with the 2D layer at the handover, by flowing the map lookups along the 2D flowmap and lifting faint map values through inverse tables
