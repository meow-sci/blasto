# Mod Feature

* [A generated spiral ramp - mesh, shadow caster, box colliders and lamps from one script](generated-deep-ramp.md) - Generates the deep spiral ramp and hall from a numpy and Pillow script that writes the GLB atlas, an invisible shadow-caster GLB, flat-colour textures, the static sub-objects and stepped box colliders spliced into the asset XML between markers, and the lamp table as C#
* [A lift built from a moving launch-pad landmark](lift-moving-landmark.md) - Runs a passenger lift by rewriting a second launch-pad landmark's GroundOffset every simulated step, carrying and waking riders from a PrepareWorker prefix, and reading the floor keys through ImGui
* [A replacement fixed camera controller with an up vector and an in-phase pose](level-horizon-camera-controller.md) - Subclasses KSA's FixedController, installs it into the main viewport through the auto-property backing field, and has it ask the mod for the camera pose and roll inside the engine's own viewport pass, with right-drag look and smooth roll
* [Asset XML, mesh and shader checks that run without the game](asset-and-mesh-validation-tools.md) - Python and shell checks that catch silent asset failures before launch, including undeclared or colliding ids, missing or case-wrong paths, shared texture files, C# names with no asset, z-fighting and degenerate UVs in GLB meshes, and GLSL that will not compile
* [Core shader library include](core-shader-library-include.md) - A header written at StarMapImmediateLoad holds absolute include paths into the player's install, so a mod's Shader asset can include KSA's Global.glsl, AtmosphereLuts.glsl and TextureSet.glsl
* [Developer file bridge and MCP server for driving a running game](dev-file-bridge-and-mcp.md) - On a developer install the mod polls a folder for JSON commands (load, step, camera, lighting, shader reload, screenshot capture with manifests) and a stdlib Python MCP server turns that folder into tools an agent can call
* [Dry volume below sea level](dry-volume-below-sea-level.md) - A radial column under the office is kept free of KSA's planet-wide ocean, by zeroing the ocean values physics sees inside it and skipping the ocean surface, underwater fog and ocean depth occlusion while the camera is inside
* [First-person body hiding with a full-body shadow](first-person-body-hiding-and-shadow.md) - An IAnimProcessor folds every bone of the walking kitten to its head for the main view only, and Draw postfixes swap the folded kitten's shadow entries for a second skinning of the whole body, so the kitten is invisible to its own eyes but still casts its full shadow
* [First-person view for a kitten on foot](first-person-kitten-view.md) - V puts the main view at the flown kitten's eyes using a head-bone pose processor and a borrowed Fixed camera mode, right-drag looks around, and a worker-thread patch on KittenLocomotion.StepGrounded turns the walk to follow the look
* [Fly the nearest craft from the office computer](computer-flies-nearest-craft.md) - Seated in the office chair, Enter hands the player's controls to the nearest craft by swapping Program.ControlledVehicle while the main view stays at the kitten's eyes and a borrowed secondary viewport films the craft for the monitor
* [Garage spot lights submitted per viewport](garage-spot-lights.md) - Ceiling lamps made of KSA's own spot lights, resubmitted every frame for every viewport from the static-object render-data postfix, with the nearest lamps flagged to fill the player's light-shadow slots
* [Ground clutter kept off the launch pads nearest the camera](ground-clutter-exclusion-zones.md) - A postfix on the private GroundClutterPlacementData.PopulateLaunchPadExclusionZones replaces the engine's first-four-pads-in-list-order clutter exclusion with the four launch pads nearest the main camera, so a mod-added pad gets its grass and trees cleared
* [Headless tests over a KSA-free Sim folder, assembly resolution and CI](headless-tests-and-ci.md) - Splits the code into a Sim folder with no KSA types that a test project links wholesale, resolves the game's assemblies from several places with a digest lock, and runs one check script from both the pre-push hook and CI, which builds against a private assemblies repository
* [Invisible shadow casters](invisible-shadow-casters.md) - Caster meshes that are never drawn are built as engine StaticMeshRenderables and pushed into the SuperMesh shadow pool each frame, so the sun and the lamps are blocked by a building whose static object casts no shadow
* [Launch-pad landmarks that stand a walkable building on Earth](office-landmarks-static-objects.md) - Stands a multi-part static object at a fixed latitude and longitude on Earth by adding IsLaunchPad landmarks to the Earth template at load, then draws it itself whenever the engine culls it
* [Live viewport image on an in-world monitor](viewport-image-on-monitor.md) - A secondary camera viewport's finished image is shown on a monitor part by repointing the part material's bindless diffuse and emissive slots at it, with an ImGui background-draw-list quad grid painted over the screen for full brightness
* [Noticing a save load with a Program.OnGameLoaded postfix](save-load-detection.md) - A Harmony postfix on Program.OnGameLoaded latches a flag that the mod's next frame step consumes to drop state from the replaced world, because StarMap has no load hook and the flight scene never ends across a load
* [Office furniture as single-part craft, kept out of saves](office-furniture-craft.md) - Sets an office chair with an IVA seat and an EVA door, and a monitor, down in the building as one-part craft built in code, and strips them from every save so a save never depends on the mod
* [One step per frame across three hooks, on the simulation clock](frame-step-plumbing.md) - Runs the mod's per-frame step from whichever of the GUI postfix, a prefix on Program.OnFrameCelestials or the frame postfix reaches it first, integrates the engine's own applied sim step exactly once, and notices save loads through a Program.OnGameLoaded postfix
* [Per-mod log file beside KSA's logs](mod-log-file.md) - Writes the mod's own batched log to Logs/KSAStructures.log under the KSA user folder, keeps the previous session's log, flushes on a timer thread and immediately on warnings, and switches to debug detail at runtime
* [Settings menu entry, settings window and optional ModMenu listing](settings-menu.md) - Adds a KSA Structures menu from the StarMapBeforeGui hook, a small settings window from StarMapAfterGui, and lists itself in ModMenu through a copied attribute without depending on it
* [Terrain decal pits dug at load](terrain-decal-pits.md) - Levels and digs Earth's terrain under the office by deserializing DecalModifierReference XML in code and inserting it into both of the Earth template's modifier lists at StarMapAllModsLoaded, before the terrain-modifier render data and the planet renderer's buffers are sized from the modifier count
* [Terrain height answered as roof, ramp or floor](terrain-height-roof-override.md) - Postfixes the camera-frame terrain height query so wheels, cameras and placement see the garage roof, the ramp slabs or the pit floor depending on who is asking, while Bepu terrain collision keeps the real pit
* [Terrain slope displacement held down live in the planet renderer's material buffer](live-terrain-material-override.md) - While the camera is near the site, reflects into PlanetRenderer's persistently mapped biome-material buffer and clamps the Grass and Beach slope materials' displacementScale to their ground materials', restoring the stored values when the camera leaves
* [Underground dark compute pass](underground-dark-compute-pass.md) - A first-priority Harmony prefix on SunbloomRenderer.Render dispatches a mod compute shader over the main view's HDR scene image, scaling the sky's ambient out of every pixel inside the dug rooms before bloom and tonemapping
