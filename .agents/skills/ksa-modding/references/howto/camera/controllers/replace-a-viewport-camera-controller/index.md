# Game Feature

* [Replace a viewport's camera controller and take input through it](overview.md) - How mods install a FixedController or IVAController subclass into a GameViewport despite the protected setters, and how a replacement controller receives and routes camera input

# How-To

* [Fetch the protected setters once with GetSetMethod(nonPublic true) and park the viewport in Fixed](replace-a-viewport-camera-controller-2.md) - gatOS caches the non-public setters of GameViewport.FixedController and ViewportBase.Mode, installs its controller, parks the viewport in Fixed without SetCameraMode's side effects and restores both on release
* [Install a FixedController subclass by writing the auto-property backing field, check it took and restore on unload](replace-a-viewport-camera-controller-1.md) - GameViewport.FixedController has a protected setter, so KSAGolf, KSAStructures and KSArmory write its compiler-generated backing field by reflection, read the property back to prove the write and put the stock controller back from StarMapUnload
* [Match the orbit camera's drag feel with 0.003 rad per pixel, a squared-2 threshold, 1.1 per wheel notch and an ease back](replace-a-viewport-camera-controller-6.md) - KSAGolf's ChaseOrbit copies KSA's orbit-camera drag constants so a chase answers the mouse like the camera the player knows; at the pinned ref only the constants are wired into the game
* [Route orbit drag, club swing and builder input through the controller and keep ImGui-captured releases from sticking a drag](replace-a-viewport-camera-controller-5.md) - KSAGolf's FixedController subclass distinguishes a looked-around view, a swing that owns the mouse and a builder that takes the whole keyboard and mouse, and shows where a release is lost to ImGui
* [Swap IvaController with a typed open-instance delegate and forward every input callback to a private FlyController](replace-a-viewport-camera-controller-3.md) - Kitchen Sink builds an Action<GameViewport, IVAController> from the protected IvaController setter, installs an IVAController subclass and forwards frame and input callbacks to a private FlyController unless another input owner is active
* [Take right-drag look through the controller with orbit-camera constants and IsMouseDrag to keep part windows shut](replace-a-viewport-camera-controller-4.md) - KSAStructures' FixedController subclass takes the right button only while its pose source exposes a look, copies KSA's orbit drag rules and answers IsMouseDrag and GetCursorMode so a look-drag never opens the part window under the cursor
