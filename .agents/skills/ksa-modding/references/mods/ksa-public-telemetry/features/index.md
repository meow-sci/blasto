# Mod Feature

* [Allocation-free formatted readout text](allocation-free-readout-text.md) - Formats every per-frame readout into stackalloc'd char spans with TryFormat and hands the spans straight to draw-list text calls, which Brutal's ImString encodes into a per-frame arena instead of allocating strings
* [Broadcast overlay on the ImGui foreground draw list](foreground-drawlist-broadcast-overlay.md) - A full-screen webcast-style bottom bar drawn straight into ImGui's foreground draw list, with anchored panels, a gradient backdrop band and sloped shelf plates, instead of an ImGui window
* [Engine diagram from real nozzle positions](engine-diagram-from-nozzle-positions.md) - Builds a top-down dot diagram of the active stage by enumerating engine controllers and rocket cores from the part tree and projecting each nozzle into vehicle assembly space, ringed by a propellant arc summed from every tank
* [Error budget and self-disable](error-budget-self-disable.md) - Wraps every per-frame entry point in try/catch, logs only the first exception of a streak, and after ten consecutive failures disables the whole mod and restores the stock flight HUD so a game update cannot leave the player with a broken screen
* [Every element as its own ImGui window](panels-as-static-imgui-windows.md) - Wraps each overlay panel in a subclass of the game's KSA.ImGuiWindow implementing IStaticWindow, so it is drawn by the game's own static-window pass like stock windows, and persists open state, position and size in the mod config because those windows opt out of imgui.ini
* [Freeze on signal loss](freeze-on-signal-loss.md) - Stops sampling and holds the last telemetry when the controlled vehicle loses control, is destroyed, or is about to exceed its structural g-load or dynamic-pressure limit, showing an acquisition-of-signal notice like a real broadcast
* [Hide and restore the stock flight HUD](hide-and-restore-stock-flight-hud.md) - Disables every enabled, non-AlwaysEnabled GaugeCanvas while the overlay is up and re-enables exactly those afterwards, pausing while the game's LAYOUTS window is open so a saved HUD layout does not record everything as switched off
* [In-flight event detection and callouts](flight-event-detection-and-callouts.md) - Infers liftoff, max Q, MECO/SECO, stage and booster separation, relights and landing from frame-to-frame deltas of engine, part, vehicle and decoupler counts, and announces them as fading banners
* [JSON config in the KSA documents folder](json-config-in-documents.md) - Stores settings, colour overrides and tuning overrides in Documents/My Games/Kitten Space Agency/KSATelemetryOverlay/config.json via Constants.DocumentsFolderPath, tolerates hand edits by dropping unreadable fields one at a time, clamps values, and saves debounced and atomically
* [Keep drawing while the game UI is hidden](draw-while-ui-hidden-drawfps-postfix.md) - Patches the private Program.DrawFps with a Harmony postfix found and applied purely through reflection, because OnFrame calls it outside the DrawUI guard that silences StarMap's UI hooks on F2
* [Live flight telemetry sampling](live-flight-telemetry-sampling.md) - Copies speed, altitude, g-load, dynamic pressure, apsides, downrange, thrust and propellant fraction of the controlled vehicle into a plain snapshot object once per frame from StarMapAfterOnFrame, for the UI to draw on the next frame
* [Live tuning window and palette by reflection](live-tuning-and-palette-reflection.md) - Exposes every public static float and int of a Tuning class and every colour field of a style class through reflection, so a debug window can edit layout and animation constants live, save only the overrides, and print the changed values back as C# source
* [Mission clock and liftoff detection](mission-clock-and-liftoff-detection.md) - A T-minus/T-plus clock that keys each mission on the vehicle's LaunchGameTime (shared by every stage split from it), detects the real liftoff moment from contact, power and climb rate, supports a hotkey countdown, and persists liftoff epochs and launch sites in the config
* [Mission timeline with planned burns](mission-timeline-with-planned-burns.md) - A scrolling mission timeline centred on now that shows detected events behind the marker and the flight computer's planned maneuver burns ahead of it, read from Vehicle.FlightComputer.BurnPlan each frame and converted to mission time
* [ModMenu entry with a standalone fallback window](modmenu-entry-with-standalone-fallback.md) - Declares its own copy of ModMenu's ModMenuEntry attribute on a static settings method so ModMenu can list it under Mods without a dependency, and draws the same settings tree as a hotkey-toggled ImGui window when ModMenu is absent, switching BeginMenu for CollapsingHeader
* [Montserrat fonts in the ImGui atlas](montserrat-fonts-in-imgui-atlas.md) - Lazily adds bundled Montserrat TTFs to the game's ImGui font atlas on the first UI frame, renders them at arbitrary sizes with the two-argument PushFont, and draws tabular digits and drop shadows on a draw list
* [Rebindable numpad hotkeys](rebindable-numpad-hotkeys.md) - Polls ImGui.IsKeyPressed for numpad toggle, settings and countdown keys stored as ImGuiKey values in the JSON config, skips them while a text field has focus, and rebinds them with a press-a-key capture loop over the ImGuiKey range
* [Staged intro and outro animation](intro-outro-animation.md) - A time-driven animator that sweeps the overlay in as five overlapping eased stages, staggers gauges from the screen edge inward, plays itself backwards as an outro, and cross-fades engine dots on state changes
