# Mod

* [Kitten Engineer Redux](overview.md) - Small StarMap mod in the spirit of Kerbal Engineer Redux that adds a staging and mass analysis panel to the vehicle editor and a configurable flight HUD with orbit, suicide-burn, planner, alert and telemetry-graph sections, all drawn from Harmony postfixes on the game's own UI methods
